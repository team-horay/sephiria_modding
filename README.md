# 세피리아 모드 가이드

세피리아 모드 커뮤니티에 참여해 주셔서 감사합니다.

[세피리아(Sephiria)](https://store.steampowered.com/app/2436940) 모드 제작 가이드, 예제, 템플릿을 모아둔 공식 저장소입니다. 
모드는 [Steam 창작마당](https://steamcommunity.com/app/2436940/workshop/)으로 배포하고, 게임이 시작할 때 구독한 모드를 읽어 적용합니다.


## 규칙

창작의 자유와 안전한 이용 환경을 위해 아래 규칙을 지켜 주세요. 규정 위반 시 모드 배포 또는 게임 이용이 제한될 수 있습니다.

1. **악성 행위 금지**: 악성코드, 백도어, 키로거, 채굴 프로그램 등 이용자의 기기·계정·정보를 침해하는 기능은 금지됩니다.
2. **비상업적 이용**: 모든 모드는 비상업적 목적으로 제작·배포해야 합니다.
3. **권리 침해 및 유해 콘텐츠 금지**: 타인의 저작권·개인정보·초상권을 침해하거나, 성적 콘텐츠 또는 혐오·괴롭힘·현실의 폭력을 조장하는 콘텐츠는 금지됩니다.
4. **플레이 방해 금지**: 게임을 고의로 오작동시키거나 다른 이용자의 정상적인 플레이를 방해해서는 안 됩니다.
5. **정보 수집 금지**: 이용자의 정보를 수집하거나 외부로 전송해서는 안 됩니다.
6. **권한 우회 금지**: 게임이나 배포 플랫폼의 구매·소유·접근 권한 확인을 부정하게 우회해서는 안 됩니다.
7. **모드 검수**: 모든 모드는 규정 위반 여부를 확인하기 위해 분석과 디컴파일을 포함한 사전 검수를 거치며, 승인까지 시간이 소요될 수 있습니다. 검수 결과 또는 승인 표시를 위조해서는 안 됩니다.
8. **게임 자산 이용**: 게임 코드·아트·사운드 등의 디컴파일·분석은 모드 제작을 위한 범위에서 허용됩니다. 다만 추출한 게임 자산 자체를 별도로 배포해서는 안 됩니다.
9. **파일 난독화 금지**: 파일들은 검수가 가능한 상태로 제공해야 하며, 난독화는 금지됩니다.
10. **사칭 및 변조 금지**: 타인의 신원을 사칭하거나 다른 사람이 만든 모드를 동의 없이 변조/배포해서는 안됩니다.



## 무엇을 만들 수 있나

모드 한 개는 폴더 하나이고, 여러개의 **모듈**을 정의할 수 있습니다.
루트의 `metadata.json`이 그 모드가 어떤 모듈로 이루어졌는지 선언합니다. 모듈 종류별로 할 수 있는 일이 다릅니다.

| 모듈 | 하는 일 | 코드 필요 |
|---|---|---|---|
| `localization` | 게임 텍스트를 해당 언어로 변경하는 모듈입니다. 언어별 파일을 폴더에 넣으면 게임 텍스트에 덮어씌워집니다. | 아니오 |
| `dll` | C#으로 작성한 코드를 게임에 붙입니다. 공개된 이벤트(`HorayModAPI`)를 구독해 여러 상황에 개입할 수 있습니다. | 예 |
| `costume` | 간단한 코스튬을 JSON과 스프라이트로 추가합니다. | 아니오 |
| `data` | DLL 없는 콘텐츠를 묶은 팩. 다른 모드가 읽어 쓸 수 있는 데이터 묶음입니다. | 아니오 |

한 모드에 여러 모듈을 함께 넣을 수 있습니다. 예를 들어 코드 모드가 자기 텍스트의 번역을 `localization` 모듈로 같이 들고 다닐 수 있습니다.



## 시작하기 전에 알아둘 것

- **모드는 게시 전에 검수를 받습니다.** 안전한 모드 커뮤니티의 유지를 위해 모든 모드는 창작마당에 공개하기 전에 검수 작업이 필요합니다. 검수 작업을 통해 코드에 악성 행위가 포함되어 있는지  검사합니다. 파일 난독화, C/C++로 컴파일 된 dll 등 검수 시스템이 읽을 수 없는 모드는 승인이 거부됨을 유의하세요. 
- **멀티플레이에서는 방의 모든 참가자가 같은 모드 집합을 켜고 있어야 합니다.** 호스트가 켠 모드 목록이 방 정보에 실리고, 참가자는 같은 모드를 구독·활성화한 뒤 입장합니다. 모드를 켜거나 끄면 게임 재시작이 필요합니다.
- **모드 ID를 처음 지정한 이후 바꾸지 마세요.** `metadata.json`의 `modId`는 다른 모드와 겹치지 않는 고유한 이름이어야합니다. 한 번 게시한 이후로 이 id를 바꾸면 그 모드에 의존하던 모드가 전부 깨질 수 있습니다.
- **게임의 C# 함수를 변경할 수 있는 `하모니 패치`는 1.1.0 이후 버전에 내장되어 있습니다.** 



## 빠른 시작

가장 간단한 모드는 번역 모드입니다. 아래의 폴더 구조를 통해 게임에 자신만의 번역을 추가할 수 있습니다.

```
my-first-mod/
├── metadata.json
└── Localization/
    └── ko-KR.json
```

```json
{
  "info": {
    "title": "내 첫 번역 모드",
    "description": "타이틀 문구를 바꿔 봅니다."
  },
  "tags": ["Localization"],
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.first-mod",
    "version": "1.0.0",
    "author": "Your Name",
    "modules": [
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```

이 폴더를 게임 설치 폴더의 `WorkshopLocal/` 아래에 두고 게임을 실행하면, 창작마당에 올리지 않고도 타이틀 화면의 창작마당 UI에 모드가 나타납니다. 
자세한 절차는 [첫 모드 만들기](docs/ko/getting-started.md)를 보세요.

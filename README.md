# 세피리아 모드 제작 가이드

세피리아 모드 커뮤니티에 참여해 주셔서 감사합니다.

[세피리아(Sephiria)](https://store.steampowered.com/app/2436940) 모드 제작 가이드, 예제, 템플릿을 모아둔 공식 저장소입니다. 모드는 [Steam 창작마당](https://steamcommunity.com/app/2436940/workshop/)으로 공유할 수 있습니다.



## 규칙

안전한 이용 환경을 위해 아래 규칙을 지켜 주세요. 규정 위반 시 모드 배포 또는 게임 이용이 제한될 수 있습니다.

1. **악성 행위 금지**: 악성코드, 백도어, 키로거, 채굴 프로그램 등 이용자의 기기·계정·정보를 침해하는 기능은 금지됩니다.
2. **비상업적 이용**: 모든 모드는 비상업적 목적으로 제작·배포해야 합니다.
3. **권리 침해 및 유해 콘텐츠 금지**: 타인의 저작권·개인정보·초상권을 침해하거나, 성적 콘텐츠 또는 혐오·괴롭힘·현실의 폭력을 조장하는 콘텐츠는 금지됩니다.
4. **플레이 방해 금지**: 게임을 고의로 오작동시키거나 다른 이용자의 정상적인 플레이를 방해해서는 안 됩니다.
5. **정보 수집 금지**: 이용자의 정보를 수집하거나 외부로 전송해서는 안 됩니다.
6. **권한 우회 금지**: 게임이나 배포 플랫폼의 구매·소유·접근 권한 확인을 부정하게 우회해서는 안 됩니다.
7. **모드 검수**: 코드(DLL)가 포함된 모드는 규정 위반 여부를 확인하기 위해 분석과 디컴파일을 포함한 검수를 거치며, 문제가 확인되면 게시 이후에도 반려될 수 있습니다. 검수 결과 또는 승인 표시를 위조해서는 안 됩니다. 파일들은 검수가 가능한 상태로 제공해야 하며, 난독화는 금지됩니다.
8. **게임 자산 이용**: 게임 코드·아트·사운드 등의 디컴파일·분석은 모드 제작을 위한 범위에서 허용됩니다. 다만 추출한 게임 자산 자체를 별도로 배포해서는 안 됩니다.
9. **사칭 및 변조 금지**: 타인의 신원을 사칭하거나 다른 사람이 만든 모드를 동의 없이 변조/배포해서는 안 됩니다.



## 시작하기 전에 알아둘 것

- 코드(DLL)가 포함된 모드는 창작마당에 업로드하면 자동으로 **검수 시스템에 접수**됩니다. 주로 코드에 악성 행위가 포함되어 있는지 검사하며, 접수되지 않았거나 반려된 모드는 다른 플레이어의 게임에서 실행되지 않습니다. 번역·코스튬처럼 코드가 없는 모드는 검수 없이 바로 올릴 수 있습니다. 검수 시스템이 읽을 수 없는 모드는 승인이 거부됨을 유의하세요. (파일 난독화, C/C++로 컴파일 된 dll 등)
- 멀티플레이에서는 방의 모든 참가자가 같은 모드 집합이 활성화 되어야 합니다. (단 번역 등 개인용 UI 모드는 제외)
- 모드를 켠 후 순서를 변경하거나 모드를 다시 비활성화 하려면 게임 재시작이 필요합니다.
- 구독한 모드는 기본으로 비활성화 되어 있습니다. 목록에서 직접 활성화할 수 있습니다.

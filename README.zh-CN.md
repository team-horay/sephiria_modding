# Sephiria 模组制作指南

感谢你加入 Sephiria 模组社区。

这里是 [Sephiria](https://store.steampowered.com/app/2436940) 的官方模组制作指南、示例与模板仓库。模组可以通过 [Steam 创意工坊](https://steamcommunity.com/app/2436940/workshop/) 分享。



## 规则

为了让所有人都能安全地游玩，请遵守以下规则。违反规定可能会导致模组发布或游戏使用受到限制。

1. **禁止恶意行为**：禁止恶意软件、后门、键盘记录器、挖矿程序，以及任何会侵害用户设备、账户或数据的功能。
2. **非商业用途**：所有模组必须以非商业目的制作和发布。
3. **禁止侵权及有害内容**：禁止侵犯他人著作权、隐私或肖像权的内容，以及包含色情内容或宣扬仇恨、骚扰、现实暴力的内容。
4. **禁止妨碍游戏**：不得故意使游戏发生故障，或妨碍其他玩家正常游玩。
5. **禁止收集数据**：不得收集用户信息或将其发送到外部。
6. **禁止绕过权限验证**：不得以不正当方式绕过游戏或发布平台的购买、所有权或访问权限验证。
7. **模组审核**：包含代码（DLL）的模组在批准前须经过审核，包括分析和反编译，以检查是否违反规则。批准可能需要一些时间。不得伪造审核结果或批准标识。文件必须以可供审核的状态提供，禁止混淆处理。
8. **游戏资产使用**：允许在制作模组所需的范围内，对游戏的代码、美术、音效等资产进行反编译和分析。但不得单独发布提取出的游戏资产本身。
9. **禁止冒充及篡改**：不得冒充他人，也不得未经同意修改并发布他人制作的模组。



## 开始之前

- 包含代码（DLL）的模组在上传到创意工坊之前需要经过**审核**。审核主要检查代码中是否存在恶意行为。翻译、服装等不含代码的模组无需审核即可直接上传。请注意，审核系统无法读取的模组（混淆过的文件、由 C/C++ 编译的 DLL 等）会被驳回。
- 多人游戏中，房间内的所有参与者必须启用相同的一组模组。（翻译等仅影响个人的 UI 模组除外。）
- 启用模组后，若要更改模组顺序或再次停用，需要重启游戏。
- 已订阅的模组默认处于停用状态。你可以在列表中自行启用。

# 첫 모드 만들기

세피리아 모드의 기초 구조를 설명하고, 모드를 만드는 방법을 간략히 설명합니다.


## 준비물

- 세피리아 모드는 스팀 창작마당 생태계에 의존하고 있으므로, 스팀 버전의 세피리아로만 모딩 환경을 경험할 수 있습니다.
- Visual Studio Code 등 고급 텍스트 편집기


## 게임 설치 폴더 찾기

1. Steam 라이브러리에서 세피리아를 오른쪽 클릭 → 관리 → 로컬 파일 보기를 통해 세피리아 설치 폴더에 접근합니다. (`Sephiria.exe`가 있는 폴더, 이하 `<게임 설치 폴더>`)
2. 맥OS에서는 같은 메뉴로 열리는, `Sephiria.app`이 있는 폴더가 `<게임 설치 폴더>`입니다. 앱 번들 안이 아니라 그 옆에 `WorkshopLocal/`을 만듭니다.


## WorkshopLocal 폴더 생성

창작마당에 업로드 하기 앞서, 모드를 제작하고 테스트 하기 위해 설치 폴더에 `WorkshopLocal/` 폴더를 만드세요.

```
<게임 설치 폴더>/
├── Sephiria.exe
└── WorkshopLocal/
    ├── my-first-mod/          ← 모드 하나
    │   ├── metadata.json      ← 모드의 핵심 파일
    │   └── ...
    └── another-mod/           ← 또 다른 모드
        └── ...
```

- `WorkshopLocal/` **바로 아래** 폴더 하나가 모드 하나입니다. 한 단계 더 깊이 넣으면 찾지 못합니다.
- 폴더 이름은 자유입니다. 게임은 폴더 이름이 아니라 `metadata.json`의 내용으로 구분합니다.
- `.`으로 시작하는 폴더(`.git` 등)는 무시됩니다. 모드 폴더를 git으로 관리해도 됩니다.
- 이 경로에 생성한 모드는 나중에 게임을 통해 창작마당으로 업로드가 가능합니다.


## 다른 위치의 폴더 쓰기

모드를 다른 드라이브나 작업 폴더에 두고 싶다면 실행 인자로 경로를 넘길 수 있습니다. Steam 라이브러리에서 세피리아 → 속성 → 일반 → 시작 옵션에 적습니다.

```
-workshop_local=D:\mods\my-first-mod
```

여러 개는 세미콜론으로 잇고, 경로에 공백이 있으면 전체를 따옴표로 감쌉니다.

```
"-workshop_local=D:\My Mods\first;D:\My Mods\second"
```

인자로 넘긴 폴더는 `WorkshopLocal/` 하위 폴더와 똑같이 취급됩니다.


## 창작마당 패널

타이틀 화면의 **스팀 창작마당** 버튼으로 엽니다.
모드를 선택하면 오른쪽에 제목·설명·썸네일과 모드를 관리하는 여러 버튼들이 보입니다.

| 버튼 | 하는 일 |
|---|---|
| 설치 폴더 열기 | 선택한 모드의 폴더를 탐색기로 엽니다 |
| 검수 요청 / 창작마당에 올리기 | 로컬 모드에만 보입니다. ([게시와 멀티플레이](publishing.md) 참고) |
| 창작마당 페이지 열기 | 게시된 모드의 Steam 페이지를 엽니다 |
| 구독 해제 | 구독한 모드에만 보입니다. 확인 후 구독을 해제합니다 |


## 켜기, 끄기, 순서

- **로컬 모드는 기본으로 켜져 있습니다.** 폴더에 넣고 게임을 실행하면 바로 적용 대상입니다.
- **구독한 모드는 기본으로 꺼져 있습니다.** 목록에서 직접 켜야 적용됩니다. 멀티플레이 방에 참가할 때는 방이 요구하는 모드 집합으로 자동 교체됩니다.
- 모드를 **끄거나 구독 해제**해도 이미 로드된 DLL은 이번 실행에서 해제가 불가능합니다. (재시작하면 반영됩니다.)
- **로드 순서**는 패널에서 끌어서 변경할 수 있습니다. 의존 관계가 있는 모드는 "의존 그룹"으로 묶여 그룹 안에서만 움직일 수 있습니다. 순서를 바꾸면 재시작이 필요합니다.
- 타이틀 화면에서만 켜기·끄기·순서 변경이 가능합니다.


## 게임이 모드 폴더에 만드는 파일

검수 요청과 업로드를 거치면 게임이 모드 폴더에 파일 몇 개를 추가합니다. 검수 승인 정보가 들어 있으니 **지우지 마세요.** 어떤 파일인지, 잃어버리면 어떻게 복구하는지는 [게시와 멀티플레이](publishing.md)에 있습니다.


## 로그 보기

게임 로그는 아래 파일에 기록됩니다. 게임을 실행할 때마다 새로 쓰이고, 직전 실행분은 `Player-prev.log`에 남습니다.

```
%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log
```

모드 관련 줄은 대괄호 태그로 시작하니 그 태그로 검색하면 됩니다.

| 태그 | 내용 |
|---|---|
| `[WorkshopModManager]` | 구독 목록 조회, 다운로드, 로컬 폴더 수집, 로딩 계획 요약 |
| `[WorkshopModRuntime]` | DLL 활성화와 번역 병합 결과 |
| `[WorkshopUploader]` | 검수 제출과 창작마당 업로드 |
| `[ModGuardClient]` | 검수 서버 통신 |
| `[WorkshopLobbyMods]` | 멀티플레이 방의 모드 집합 비교 |
| `모드 내 언어 파일 발견` | 번역 파일별로 읽힌 키 수 |


## AddOns 폴더에 대해

패널에 "로컬 모드 (AddOns 폴더)" 항목이 보일 수 있습니다. 구버전 모딩 기능이므로 새 모드에는 쓰지 마세요.

# 게시와 멀티플레이

> 작성 중입니다. 업로드 절차, 검수 상태, 멀티플레이 규칙은 아직 채워지지 않았습니다.

## 게임이 모드 폴더에 만드는 파일

검수 요청과 업로드를 거치면 모드 폴더에 파일이 자동으로 추가됩니다. 이 파일들에는 당신의 검수 승인 정보가 포함되어 있으므로 **지우지 마세요.** 모드 폴더를 git으로 관리한다면 이 세 파일도 함께 커밋해 두는 것이 안전합니다. 컴퓨터를 바꾸거나 포맷하면 이 파일이 있어야 같은 창작마당 항목을 이어서 갱신할 수 있습니다.

| 파일 | 내용 |
|---|---|
| `uploadticket.json` | 검수 티켓과 창작마당 게시 번호. 이게 없으면 게임은 이 폴더를 아직 게시한 적 없는 새 모드로 봅니다. |
| `mod-guard-manifest.json`, `mod-guard.sig.json` | 검수 승인 증명. 승인된 파일 목록과 서명입니다. 내용을 고치면 승인이 무효가 됩니다. |

## 파일을 잃어버렸을 때

**증명 파일(`mod-guard-manifest.json`, `mod-guard.sig.json`)만 없고 `uploadticket.json`은 남아 있다면** 패널에서 그 모드를 선택하고 **승인 증명 받기** 버튼을 누르면 검수 서버에서 다시 받아 옵니다. 손으로 만들 것은 없습니다.

**포맷 등으로 `uploadticket.json`까지 잃었다면** 게임은 그 폴더를 새 모드로 보기 때문에, 그대로 올리면 기존 글이 갱신되지 않고 새 글이 하나 더 생깁니다. 기존 글을 이어서 갱신하려면 다음 순서로 복구합니다.

1. 창작마당에서 자기 모드를 구독합니다.
2. Steam이 내려받은 폴더(`<Steam 라이브러리>/steamapps/workshop/content/2436940/<창작마당 번호>/`)를 통째로 `WorkshopLocal/` 아래에 복사합니다. 폴더 이름은 아무거나 괜찮습니다.
3. 복사한 폴더에 `uploadticket.json`을 아래 내용으로 만듭니다. 번호는 창작마당 페이지 URL의 `id=` 뒤 숫자입니다.

```json
{
  "modId": "yourname.first-mod",
  "publishedFileId": 123456789
}
```

4. 게임을 실행하면 패널에 "검수 요청 전"으로 보입니다. 검수 요청 → 승인 → 승인 증명 받기 → 창작마당에 올리기를 다시 거치면 **기존 글이 갱신**됩니다.

주의할 점 두 가지입니다.

- 창작마당 번호를 `metadata.json`에 적어도 아무 효과가 없습니다. 게임은 `uploadticket.json`의 번호만 봅니다.
- 다른 모드를 만들려고 기존 모드 폴더를 복제했다면 `uploadticket.json`과 증명 파일을 **반드시 지우세요.** 남겨 두면 새 모드가 원래 모드의 창작마당 글을 덮어씁니다.

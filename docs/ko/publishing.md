# 창작마당에 올리기

모드를 창작마당에 올리는 방법, 검수 시스템, 멀티플레이 시 플레이어끼리 모드가 동기화되는 방법에 대해 설명합니다.


## 올리기 전에 확인할 것

- 창작마당에 모드를 올리기 위해서는 **`thumbnail.png`**(PNG 또는 JPG, 1MB 미만)가 필수로 존재해야 합니다.
- `info.title`은 128자, `info.description`은 7999자까지입니다. 여러 언어로 적었다면 `en-US`가 창작마당 페이지에 올라갑니다.
- `tags`에 창작마당 카테고리를 적습니다. [metadata.json 레퍼런스](metadata.md)에서 사용할 수 있는 카테고리를 확인하세요.
- 폴더 안의 파일이 전부 검수 대상이 되므로, 모드 폴더에 게임 DLL 사본, `.pdb`, 빌드 중간 산출물이 섞여 있지 않은지 확인하세요.

## 게시 절차

1. 세피리아를 실행합니다.
2. 타이틀 화면의 '스팀 창작마당' 패널을 열어 내가 작성한 모드를 확인합니다.
3. 내 모드를 선택합니다.
4. 코드(DLL)가 포함된 모드는 코드 검수 과정을 거칩니다.
5. 코드를 포함하지 않는 모드는 즉시 창작마당에 업로드할 수 있습니다.
6. 업로드된 창작마당 페이지로 이동하여, 구독 등 마지막 테스트를 진행한 후 게시 상태를 '공개'로 변경합니다.

## 코드 검수

- 검수 시스템은 모드 폴더의 모든 파일을 확인합니다. DLL은 디컴파일해 외부 통신, 파일 접근, 난독화, 악성 동작이 있는지 검사하고, 이미지·소리·JSON 같은 데이터 파일은 형식이 올바른지 확인합니다.
- 문제가 없으면 자동으로 승인되고, 의심스러운 부분이 있으면 운영자가 직접 확인합니다. 악성 행위가 분명하면 자동으로 반려됩니다.
- 검수는 자동 분석과 운영자 확인으로 이루어지며, 이러한 검수 시스템이 모든 위험을 찾아낼 수는 없음을 이해합니다. 다만 이러한 사전 검수 및 승인 절차를 통해 악성 모드가 퍼지는 것을 줄이고자 합니다. 여러분의 협조에 감사드립니다.
- 코드 포함 여부는 파일 이름이 아니라 **내용**으로 판정합니다. `dll` 모듈이 없어도 `libraries`가 있거나 확장자를 바꾼 DLL·EXE가 들어 있으면 검수 대상이 됩니다.
- 코드 검수를 받는 모드는 폴더를 압축한 크기가 20MB 이하여야 합니다.

## 승인 증명 (코드가 포함된 모드에 한함)

- 코드가 포함된 모드의 경우 승인 증명을 받습니다.
- 해당 모드 파일의 내용이 승인본과 같다는 것을 증명합니다.
- DLL 모드는 이 증명 과정을 거쳐야만 모드를 내려받은 플레이어가 코드를 실행할 수 있습니다.
- 증명을 받은 후 파일이 하나라도 변경되면 증명이 무효가 되고 다시 검수를 받아야 합니다.

## 게시 상태와 공개 전환

- 처음 올리면 게시 상태는 `미등록`으로 만들어집니다.
- 공개 전에 직접 구독하여 설치본이 제대로 동작하는지 확인 후 '공개'로 변경하세요.
- 페이지 설명, 스크린샷, 다른 언어 설명 등은 스팀 창작마당 게시글 페이지에서 수정 가능합니다.

## 모드 업데이트 방법

게시 절차와 동일한 방식으로 모드를 업데이트할 수 있습니다.

- DLL 모드는 다시 승인 증명을 받아야 합니다.
- `modId`는 변경하지 마세요. 다른 모드로 간주되어 의존성 등이 깨질 수 있습니다.
- 업데이트마다 `metadata.json`의 `version` 숫자를 올릴 수 있습니다. (선택 사항이지만 권장)

## 업로드 티켓

검수 요청과 업로드를 거치면 모드 폴더에 아래 파일이 추가됩니다. 이 파일들에는 당신의 검수 승인 정보가 포함되어 있으므로 **지우지 마세요.** 모드 폴더를 git으로 관리한다면 이 세 파일도 함께 커밋해 두는 것이 안전합니다. 컴퓨터를 바꾸거나 포맷하면 이 파일이 있어야 같은 창작마당 항목을 이어서 갱신할 수 있습니다.

| 파일 | 내용 |
|---|---|
| `uploadticket.json` | 검수 티켓과 창작마당 게시 번호. 이게 없으면 게임은 이 폴더를 아직 게시한 적 없는 새 모드로 봅니다. |
| `mod-guard-manifest.json`, `mod-guard.sig.json` | 검수 승인 증명. 승인된 파일 목록과 서명입니다. 내용을 고치면 승인이 무효가 됩니다. |

파일을 잃어버렸을 때 복구하는 방법은 [FAQ](faq.md)에 있습니다.

## 승인 철회

게시 이후 규칙 위반이 확인되면 운영자가 승인을 철회할 수 있습니다. 철회된 모드는 설치되어 있어도 모드를 불러오지 않으며, 패널에 "검수 승인이 철회됨"으로 표시됩니다. 


## 멀티플레이 규칙

### 멀티플레이 로비 구성

호스트가 멀티플레이 로비를 만들면 **호스트가 활성화한 모드 목록**이 로비에 함께 등록됩니다.

- `installation`이 `host_only`인 모드:  참가자에게 설치를 요구하지 않고 목록에만 표시됩니다.
- `multiplayer.installation`이 `everyone`(또는 미선언)인 모드: 참가자도 설치가 필요합니다.
- 코스튬 모드와 데이터 모드: 참가자도 설치가 필요합니다.

### 참가

플레이어의 현재 모드 구성과 입장할 로비의 모드 구성이 다르면 '다운로드 → 활성화 → 게임 재시작 후 입장 시도'의 절차를 거칩니다.

### WorkshopLocal에 설치된 테스트 모드

`WorkshopLocal/`의 로컬 모드가 로드된 게임에서는 멀티플레이어가 불가능합니다. 멀티플레이 테스트는 창작마당에 올린 뒤 로컬 폴더를 치우고 구독본으로 하세요. Unlisted 상태에서도 링크로 구독할 수 있습니다.

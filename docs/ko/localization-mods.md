# 번역 모드

번역 모드는 게임 텍스트를 바꾸는 모드입니다. 코드가 필요 없고, 폴더 하나와 JSON 파일 몇 개로 끝납니다. 오탈자 수정, 특정 용어 교체, 다른 말투로 바꾸기, 게임이 지원하지 않는 언어 추가까지 전부 이 방식으로 합니다.

이 문서를 따라 하면 10분 안에 타이틀 화면의 문구가 바뀐 모드를 눈으로 확인할 수 있습니다.

## 동작 원리

게임은 언어마다 **키 → 문자열** 테이블을 하나씩 가지고 있습니다. 번역 모드의 JSON 파일은 같은 모양의 테이블이고, 게임은 모드의 테이블을 원본 위에 **키 단위로 덮어씁니다.**

- 모드 파일에 있는 키만 바뀝니다. 나머지 텍스트는 원본 그대로입니다. 그래서 파일에는 **바꾸고 싶은 키만** 넣으면 됩니다.
- 파일 이름이 곧 언어입니다. `ko-KR.json`은 한국어 테이블에, `en-US.json`은 영어 테이블에 덮어씌워집니다.
- 번역 모드가 여럿이면 활성화 순서대로 덮어씁니다. 같은 키를 두 모드가 바꾸면 **뒤에 오는 모드**가 이깁니다.
- 적용 시점은 타이틀 화면에 들어갈 때입니다. 게임을 껐다 켤 필요 없이 창작마당 패널에서 모드를 켜면 바로 반영됩니다.

## 1. 폴더 만들기

게임 설치 폴더 안의 `WorkshopLocal/` 아래에 모드 폴더를 만듭니다. `WorkshopLocal/`이 없으면 직접 만드세요. 이 폴더에 있는 모드는 창작마당에 올리지 않아도 게임이 읽습니다.

```
<게임 설치 폴더>/
└── WorkshopLocal/
    └── my-first-mod/
        ├── metadata.json
        └── Localization/
            └── ko-KR.json
```

폴더 이름은 아무거나 괜찮습니다. 게임은 폴더 이름이 아니라 `metadata.json` 안의 `modId`로 모드를 구분합니다.

## 2. metadata.json 쓰기

```json
{
  "info": {
    "title": { "ko-KR": "내 첫 번역 모드", "en-US": "My First Translation Mod" },
    "description": { "ko-KR": "타이틀 문구를 바꿔 봅니다.", "en-US": "Changes the title screen text." }
  },
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.first-mod",
    "version": "1.0.0",
    "author": "Your Name",
    "multiplayer": { "installation": "local_only", "support": "supported" },
    "modules": [
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```

- `modId`는 소문자 영문·숫자·점·하이픈·밑줄만 쓸 수 있습니다. 본인 이름이나 닉네임을 앞에 붙이면 다른 사람 모드와 겹치지 않습니다.
- `path`는 언어 파일이 든 **폴더** 이름입니다. 파일 이름을 적으면 오류입니다. 대소문자까지 실제 폴더와 같아야 합니다.
- 번역만 바꾸는 모드는 다른 참가자에게 영향이 없으므로 `installation`은 `local_only`가 맞습니다. 멀티플레이 방 정보에도 실리지 않습니다.
- 파일은 **UTF-8**로 저장하세요. 메모장이라면 "다른 이름으로 저장"에서 인코딩을 UTF-8로 고릅니다.

모든 필드의 의미는 [metadata.json 레퍼런스](metadata.md)를 보세요.

## 3. 언어 파일 쓰기

`Localization/ko-KR.json`:

```json
{
  "Title_GameStart": "모험 시작",
  "Title_Quit": "그만하기"
}
```

형식은 평평한 객체 하나입니다. 키는 문자열, 값도 문자열이고, 중첩 객체나 배열은 쓸 수 없습니다. 마지막 항목 뒤에 쉼표를 붙이면 파일 전체가 거부되니 주의하세요.

## 4. 확인하기

1. 게임을 실행합니다.
2. 타이틀 화면에서 창작마당 패널을 엽니다. 모드 목록에 "내 첫 번역 모드"가 보여야 합니다. `WorkshopLocal/`에 둔 모드는 기본으로 켜져 있습니다.
3. 패널을 닫으면 타이틀의 "게임 시작"이 "모험 시작"으로 바뀌어 있습니다.

보이지 않거나 바뀌지 않으면 [문제 해결](#문제-해결)을 보세요.

## 바꿀 키 찾기

원본 언어 파일은 게임 설치 폴더 안에 있습니다.

```
<게임 설치 폴더>/Sephiria_Data/StreamingAssets/Localization/
├── ko-KR.json
├── en-US.json
├── ja-JP.json
└── ...
```

이 파일을 텍스트 편집기로 열어 바꾸고 싶은 문구를 검색하면 키가 나옵니다. **원본 파일은 수정하지 마세요.** 게임 업데이트 때 덮어씌워지고, Steam 파일 무결성 검사에서 되돌아갑니다. 키를 찾아 모드 파일에 옮겨 적는 방식으로만 작업합니다.

키 이름의 앞부분으로 어떤 텍스트인지 짐작할 수 있습니다.

| 접두어 | 내용 |
|---|---|
| `Talk_`, `Say_`, `BossSpeech_` | NPC·보스 대사 |
| `Item_` | 아티팩트·아이템 이름과 설명 |
| `Charm_`, `CharmActivateCriteria_` | 아티팩트 효과와 발동 조건 |
| `Weapon_`, `WeaponAddon_`, `WeaponAction_`, `WeaponUniqueEffect_` | 무기 이름·효과·액션 |
| `Status_`, `Buff_`, `Debuff_`, `EffectHUD_` | 스탯·버프·디버프 |
| `UI_`, `Title_`, `SystemMessage_` | 메뉴·버튼·시스템 메시지 |
| `TutorialMessageBox_`, `QuestObjective_` | 튜토리얼·퀘스트 목표 |
| `Lore_`, `Journey_`, `Chapter` | 로어·여정·챕터 텍스트 |
| `Costume_`, `TreeShopItem_`, `Miracle_`, `HardModeShard_` | 코스튬·나무 상점·기적·하드모드 파편 |
| `#`로 시작 | 언어 설정 값. 아래 [새 언어 추가](#새-언어-추가) 참고 |

## 반드시 지켜야 할 것

게임 텍스트에는 실행 중에 치환되거나 해석되는 표기가 섞여 있습니다. 이것을 빠뜨리거나 바꾸면 숫자가 사라지거나, 키워드 링크가 깨지거나, 텍스트가 통째로 이상하게 나옵니다.

**그대로 두어야 하는 것**

| 종류 | 예 | 설명 |
|---|---|---|
| 자리표시자 | `{VALUE}`, `{EFFECT0}`, `{LV}`, `{COUNT}`, `{ITEMNAME}`, `{COUNTER}/{GOAL}` | 실행 중 숫자나 이름으로 바뀝니다. 중괄호 안은 한 글자도 바꾸지 마세요 |
| 게임 태그 | `<tag=FinalDamage>`, `<tag=WeaponAction_Fury>`, `<tag=TEXT:Qliphoth>` | 키워드 툴팁과 아이콘으로 바뀝니다. 태그 안의 이름은 대소문자까지 고정입니다 |
| 서식 태그 | `<color=red>…</color>`, `<sprite="Keyword" name=Dice>`, `<indent=10>` | 텍스트 서식입니다. 여는 태그와 닫는 태그를 짝 맞춰 두세요 |
| 줄바꿈 | `\n` | JSON 문자열 안에서 줄바꿈입니다 |

원문과 다른 위치로 옮기는 것은 괜찮습니다. 예를 들어 `"<tag=Defense>(을)를 {EFFECT0} 무시합니다"`를 `"{EFFECT0}만큼 <tag=Defense>(을)를 무시합니다"`로 바꾸는 것은 문제없습니다. 빠뜨리거나 철자를 바꾸는 것만 안 됩니다.

**한국어 조사**: 원문에 `(이)가`, `(을)를`, `(은)는`처럼 괄호로 적힌 조사는 게임이 앞 단어에 맞춰 자동으로 고릅니다. 태그 뒤에 오는 단어는 실행 전까지 알 수 없기 때문입니다. 한국어 모드에서도 이 표기를 그대로 쓰세요.

**공식 용어**: 게임 안에서 같은 개념은 같은 단어로 불립니다. 바꾸기 전에 원본 파일에서 그 단어가 다른 키에서도 쓰이는지 확인하세요. 한 곳만 바꾸면 같은 화면에서 두 가지 이름이 보입니다.

## 새 언어 추가

게임이 지원하지 않는 언어를 통째로 추가할 수도 있습니다. 파일 이름이 새 언어 코드이면 게임은 그것을 새 언어로 등록하고 언어 설정 목록에 보여 줍니다.

```
Localization/
└── vi-VN.json
```

이때는 몇 가지가 더 필요합니다.

- **전체 키를 번역**하세요. 모드 파일에 없는 키는 빈 값이 아니라 **영어**(영어도 없으면 한국어)로 표시됩니다. 원본 `en-US.json`을 복사해 시작하는 것이 가장 쉽습니다.
- **`#`로 시작하는 설정 키**를 채우세요. `#LanguageName`은 언어 설정 목록에 보이는 이름, `#FontName`은 사용할 글꼴 이름입니다. `#Colon`, `#Bullet`, `#ParenthesisOpen` 같은 구두점 키도 그 언어 관습에 맞게 바꿉니다.
- **글꼴에 그 문자가 있어야 합니다.** 게임에 들어 있는 글꼴이 다루지 못하는 문자 체계(예: 아랍 문자, 데바나가리)는 네모로 표시됩니다. 라틴·키릴·CJK·태국 문자는 기존 글꼴로 표시됩니다. 다른 문자 체계가 필요하면 디스코드로 문의해 주세요.
- `installation`은 그대로 `local_only`입니다. 언어는 각자 고르는 것이라 다른 참가자에게 요구할 필요가 없습니다.

## 창작마당에 올리기

로컬에서 확인이 끝나면 패키지 루트에 `thumbnail.png`(1MB 미만)를 넣고 타이틀 창작마당 패널에서 업로드합니다. 번역 모드는 코드가 없으므로 **검수 없이 바로 게시**됩니다. 절차는 [게시와 멀티플레이](publishing.md)를 보세요.

업로드 후 내가 올린 모드를 구독하면 `WorkshopLocal/`의 사본과 창작마당 사본이 동시에 존재합니다. 이 경우 로컬 사본이 우선하고 창작마당 사본은 쉽니다. 로컬에서 계속 고치면서 테스트해도 되고, 끝났으면 로컬 폴더를 지우면 됩니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 패널에 모드가 안 보임 | 폴더가 `<게임 설치 폴더>/WorkshopLocal/` 바로 아래에 있는지. 한 단계 더 깊으면 못 찾습니다 |
| 패널에 보이지만 "매니페스트 없음" | `metadata.json`에 `mod` 객체가 없음 |
| 패널에 오류가 표시됨 | 오류 문구가 원인입니다. `path` 대소문자, 쉼표 빠짐, 따옴표 짝 같은 JSON 문법을 확인하세요. [metadata.json 레퍼런스](metadata.md#자주-하는-실수)에 흔한 사례가 있습니다 |
| 모드는 켜졌는데 텍스트가 안 바뀜 | 키 이름이 원본과 글자 하나까지 같은지. 파일 이름이 현재 게임 언어와 같은지(`ko-KR.json`은 한국어에서만 보입니다) |
| 일부 키만 안 바뀜 | 다른 번역 모드가 같은 키를 뒤에서 덮어쓰고 있는지. 패널에서 순서를 바꿔 보세요 |
| 텍스트에 `{VALUE}`가 그대로 보임 | 자리표시자 철자가 원문과 다름. 원문에서 그대로 복사하세요 |
| 텍스트에 `<tag=…>`가 그대로 보임 | 태그 이름 철자나 대소문자가 다름 |
| 한글이 깨져 보임 | 파일이 UTF-8이 아님. UTF-8로 다시 저장하세요 |
| 파일 하나가 통째로 무시됨 | 그 파일의 JSON 문법 오류. 패널 상세 또는 `Player.log`에 파일 이름과 함께 오류가 남습니다 |

로그 파일은 `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log`에 있습니다. "모드 내 언어 파일 발견"으로 검색하면 어떤 파일이 몇 개의 키로 읽혔는지 보입니다.

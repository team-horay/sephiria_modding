# Föremålslista

- Dolda, inaktiverade och oidentifierade föremål är inte med.
- **Var försiktig med föremål som har kolumnen Upplåsning ifylld.**
  - De här föremålen låses upp via Ödesinskription, eller fås bara via särskilda vägar som fickdimensionens butik eller den misstänkta hatthandlaren.
  - Föremål som ges som startföremål delas ut oavsett om de är upplåsta eller inte, så lägg bara till dem när du verkligen behöver det.

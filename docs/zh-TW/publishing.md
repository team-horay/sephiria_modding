# 發布至工作坊

本頁說明如何將模組上傳至 Steam 工作坊、審核系統如何運作，以及多人遊戲中模組如何在玩家之間同步。


## 上傳之前

- 要將模組上傳至工作坊，必須有預覽圖（PNG 或 JPG，小於 1 MB）。透過 `info.preview` 設定，或在模組資料夾中放入 `thumbnail.png`。詳情請參閱 [metadata.json 參考](metadata.md#preview)。
- `info.title` 最多 128 個字元，`info.description` 最多 7999 個字元。如果以多種語言撰寫，工作坊頁面會使用 `en-US` 版本。
- 在 `tags` 中填入工作坊分類。可用的分類請參閱 [metadata.json 參考](metadata.md)。
- 資料夾中的每個檔案都會接受審核，請確認模組資料夾中沒有遊戲 DLL 的副本、`.pdb` 檔案或建置的中間產物。

## 發布步驟

1. 啟動 Sephiria。
2. 在標題畫面開啟 **Steam 工作坊** 面板，找到你製作的模組。
3. 選取你的模組。
4. 含有程式碼（DLL）的模組會經過程式碼審核。
5. 不含程式碼的模組可以直接上傳至工作坊。
6. 前往已上傳的工作坊頁面，做訂閱等最後測試，然後將可見性改為「公開」。

## 程式碼審核

- 審核系統會檢查模組資料夾中的每個檔案。DLL 會被反編譯，檢查網路通訊、檔案存取、混淆與惡意行為；圖片、音效、JSON 等資料檔則會檢查格式是否有效。
- 若未發現問題，模組會自動核准；若有任何可疑之處，則由營運人員手動檢查。明顯惡意的模組會被自動拒絕。
- 審核結合了自動分析與營運人員檢查，我們也明白沒有任何審核系統能攔截所有風險。儘管如此，我們仍希望透過這個事前審核與核准流程減少惡意模組的散布。感謝你的配合。
- 模組是否含有程式碼是依檔案**內容**判斷，而非檔名。即使沒有 `dll` module，只要有 `libraries`，或含有更改副檔名的 DLL 或 EXE，模組仍需接受審核。
- 需要程式碼審核的模組，其資料夾壓縮後必須在 20 MB 以下。

## 審核憑證（僅限含程式碼的模組）

- 含有程式碼的模組會收到審核憑證。
- 它證明模組的檔案與核准版本完全相同。
- DLL 模組必須先通過此認證，下載該模組的玩家才能執行其程式碼。
- 認證後只要有任何一個檔案變更，憑證就會失效，模組必須重新審核。

## 可見性與公開

- 首次上傳時，可見性會設為 `Unlisted`（不公開）。
- 公開之前，請先自行訂閱，確認安裝下來的版本運作正常，然後再改為「公開」。
- 頁面說明、截圖、其他語言的說明等，可以在 Steam 工作坊的物品頁面上編輯。

## 更新模組

更新模組的方式與發布時相同。

- DLL 模組需要新的審核憑證。
- 請勿更改 `modId`。否則會被視為不同的模組，可能導致相依性等問題。
- **每次更新都務必提高 `metadata.json` 中的 `version`。** 加入多人遊戲大廳時會比較模組版本，如果內容改了但版本沒改，模組內容不同的玩家可能會進到同一場遊戲而發生問題。

## 上傳票證

申請審核並上傳後，下列檔案會被加入你的模組資料夾。它們包含你的審核核准資訊，所以**請勿刪除**。如果你用 git 管理模組資料夾，最保險的做法是連這三個檔案一起提交。如果更換電腦或重灌系統，你需要這些檔案才能繼續更新同一個工作坊物品。

| 檔案 | 內容 |
|---|---|
| `uploadticket.json` | 審核票證與工作坊物品 ID。沒有它，遊戲會把資料夾視為從未發布過的新模組。 |
| `mod-guard-manifest.json`、`mod-guard.sig.json` | 審核憑證：已核准的檔案清單與簽章。編輯它們會使核准失效。 |

遺失這些檔案時的復原方式請參閱[常見問題](faq.md)。

## 撤銷核准

如果發布後發現違反規則，營運人員可以撤銷核准。被撤銷的模組即使已安裝也不會載入，並會在面板中顯示為「審核核准已撤銷」。


## 多人遊戲規則

### 多人遊戲大廳設定

房主建立多人遊戲大廳時，**房主已啟用的模組清單**會登錄到大廳。

- `installation` 設為 `host_only` 的模組：參與者不需要安裝；只會顯示在清單中。
- `multiplayer.installation` 設為 `everyone`（或未宣告）的模組：參與者也必須安裝。
- 服裝模組與資料模組：參與者也必須安裝。

### 加入

若玩家目前的模組設定與大廳不同，會經過以下步驟：下載 → 啟用 → 重新啟動遊戲並再次嘗試加入。

### 安裝在 WorkshopLocal 中的測試模組

載入了 `WorkshopLocal/` 本機模組的遊戲無法進行多人遊戲。要測試多人遊戲，請將模組上傳至工作坊、清空本機資料夾，並使用訂閱下來的版本。即使物品為 `Unlisted`（不公開），也可以透過連結訂閱。

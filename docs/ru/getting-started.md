# Ваш первый мод

В этом руководстве описана базовая структура мода для Sephiria, а также пошагово показано, как собрать свой первый мод и проверить его в игре.

## Что понадобится

- Удобный текстовый редактор (например, [Visual Studio Code](https://code.visualstudio.com/))

## Найдите папку установки игры

Откройте папку, в которую установлена Sephiria.

- Из библиотеки Steam
  - `Библиотека Steam → правый клик по Sephiria → Управление → Посмотреть локальные файлы`
- Windows (путь установки по умолчанию)
  - `C:\Program Files (x86)\Steam\steamapps\common\Sephiria`
- macOS (путь установки по умолчанию)
  - `~/Library/Application Support/Steam/steamapps/common/Sephiria` (папка, в которой находится `Sephiria.app`)

## Создайте папку WorkshopLocal и папку своего мода

1. Создайте папку `WorkshopLocal/` в папке установки игры.
2. Внутри неё создайте папку для своего мода.
   - Sephiria считает каждую папку отдельным модом.
   - Созданные здесь моды можно тестировать в игре и загружать в Мастерскую Steam.

В этом руководстве вы соберёте `my-first-mod`, мод, который меняет текст кнопки «Начать игру» на титульном экране на «Hello World!». Готовая структура выглядит так:

```
<папка установки игры>/
├── Sephiria.exe
└── WorkshopLocal/
    ├── my-first-mod/          ← один мод
    │   ├── metadata.json      ← ключевой файл, описывающий мод
    │   ├── thumbnail.png      ← миниатюра мода (обязательна для загрузки в Мастерскую)
    │   └── Localization/      ← папка, которую читает модуль локализации
    │       └── en-US.json     ← текст, который нужно заменить
    └── another-mod/           ← ещё один мод
        └── ...
```

## Файл metadata.json

- Создайте `metadata.json` в папке мода и вставьте в него содержимое ниже.
- `metadata.json`: ключевой файл, описывающий ваш мод.
- `yourname`: замените на свой ник.
- Сохраните файл в кодировке **UTF-8**. В Блокноте выберите UTF-8 в поле «Кодировка» окна «Сохранить как».
- Значение каждого поля описано в [Справочнике по metadata.json](metadata.md).

```json
{
  "info": {
    "title": "My First Mod",
    "description": "Hello World!"
  },
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.my-first-mod",
    "version": "0.0.1",
    "author": "Your Name",
    "multiplayer": { "installation": "local_only" },
    "modules": [
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```

## Создайте языковой файл

- Создайте папку `Localization/` внутри папки мода.
- Внутри `Localization/` создайте файл `en-US.json` с содержимым ниже.
- Для теста можно также переименовать файл в код вашего языка.

```json
{
  "Title_GameStart": "Hello World!"
}
```

## Проверьте результат

Теперь можно проверить, работает ли мод.

1. Запустите Sephiria.
2. Установив в игре английский язык, посмотрите на титульный экран: кнопка «Start Game» теперь называется «Hello World!». Моды в `WorkshopLocal/` включены по умолчанию, так что включать их вручную не нужно.
3. Нажмите кнопку **Мастерская Steam** на титульном экране, чтобы открыть панель Мастерской. «My First Mod» должен появиться в разделе «Мои моды».

### Мой мод не применяется!

- Проверьте, корректен ли синтаксис JSON.
- Значение `path` в `metadata.json` должно в точности совпадать с реальным именем папки, включая регистр.
- Убедитесь, что `metadata.json` сохранён в кодировке UTF-8.
- Убедитесь, что язык игры совпадает с языком в имени файла.

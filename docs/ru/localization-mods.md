# Моды локализации

Основы создания мода описаны в разделе [Ваш первый мод](getting-started.md), поэтому на этой странице собраны общие правила для модов локализации.
В [`examples/translation-sample`](../../examples/translation-sample) есть полный пример, который можно скопировать прямо в `WorkshopLocal/` и попробовать.



## Как это работает

- В игре для каждого языка есть одна таблица **ключ → строка**. При загрузке мода значения из мода перезаписывают исходную таблицу.
- В вашем файле нужны только те ключи, которые вы хотите изменить.
- Имя файла определяет язык. `ko-KR.json` перезаписывает корейскую таблицу, а `en-US.json` перезаписывает английскую.
- Если несколько модов локализации задают один и тот же ключ, побеждает мод, загруженный позже.
- Мод, который меняет только текст, не влияет на других участников, поэтому рекомендуем указать `multiplayer.installation` в `metadata.json` как `local_only`.
- И ключи, и значения являются строками. Вложенные объекты и массивы не допускаются.
- Сохраняйте файлы в кодировке **UTF-8**.

```
my-translation-mod/
├── metadata.json              ← добавьте { "type": "localization", "path": "Localization" } в modules
├── thumbnail.png
└── Localization/
    └── ko-KR.json
```



## Что не нужно переводить

Игровой текст содержит выражения, которые интерпретируются во время выполнения.
Не переводите приведённый ниже текст; оставляйте его на английском в точности как есть (с учётом регистра).

| Тип    | Пример                                                                     | Описание                                 |
| ----- | --------------------------------------------------------------------------- | ------------------------------------------- |
| Ключевые слова   | `{VALUE}`, `{EFFECT0}`, `{LV}`, `{COUNT}`, `{ITEMNAME}`, `{COUNTER}/{GOAL}` | Во время выполнения заменяются числами или именами. Не меняйте ни одного символа внутри фигурных скобок.   |
| Игровые теги | `<tag=FinalDamage>`, `<tag=WeaponAction_Fury>`, `<tag=TEXT:Qliphoth>`       | Заменяются подсказками по ключевым словам и иконками. Имена внутри тегов фиксированы, включая регистр. |
| Теги форматирования | `<color=red>…</color>`, `<sprite="Keyword" name=Dice>`, `<indent=10>`       | Форматирование текста. Открывающие и закрывающие теги должны быть парными.        |
| Переносы строк   | `\n`                                                                        | Перенос строки внутри JSON-строки.                        |




## Добавление нового языка

- Вы можете добавить и язык, который игра не поддерживает. Если имя файла является новым кодом языка, игра регистрирует его как новый язык и показывает в списке настроек языка.
- Исходные языковые файлы находятся в `<папка установки игры>/Sephiria_Data/StreamingAssets/Localization/`, по одному на язык; используйте их как образец при переводе.
- Игра уже поддерживает языки `ko-KR`, `en-US`, `ja-JP`, `zh-CN`, `zh-TW`, `de-DE`, `fr-FR`, `es-ES`, `it-IT`, `pl-PL`, `pt-BR`, `ru-RU`, `sv-SE`, `th-TH` и `tr-TR`.
- **Переведите все ключи.** Ключи, отсутствующие в файле мода, не отображаются пустыми; вместо них подставляется **английский** текст (или корейский, если английского тоже нет). Проще всего начать с копии исходного `en-US.json`.
- **Заполните служебные ключи, начинающиеся с `#`.** `#LanguageName` является названием, которое отображается в списке настроек языка, а `#FontName` задаёт используемый шрифт. Настройте ключи пунктуации, такие как `#Colon`, `#Bullet` и `#ParenthesisOpen`, в соответствии с правилами этого языка.
- Для `#FontName` можно выбрать один из встроенных в игру шрифтов. В игре есть шрифты для следующих систем письма:

| Система письма | `#FontName` |
|---|---|
| Латиница, кириллица, хангыль | `GalCyrillic` |
| Японский | `JF-Dot-MPlus10` |
| Упрощённый китайский | `Fusion_Pixel_10_Simple` |
| Традиционный китайский | `BoutiqueBitmap9x9` |
| Тайский | `NotoSansThai` |



## Устранение неполадок

| Симптом | Что проверить |
|---|---|
| Мод включён, но текст не меняется | Совпадает ли имя ключа с исходным вплоть до каждого символа. Совпадает ли имя файла с текущим языком игры (`ko-KR.json` применяется только при корейском языке). |
| Не меняются только некоторые ключи | Не перезаписывает ли тот же ключ другой мод локализации, загруженный позже. Попробуйте изменить порядок в панели. |
| `{VALUE}` отображается в тексте как есть | Ключевое слово написано иначе, чем в оригинале. Скопируйте его напрямую из исходного текста. |
| `<tag=…>` отображается в тексте как есть | Написание или регистр имени тега отличаются. |
| Корейский (или другой неанглийский) текст отображается искажённо | Файл не в UTF-8. Сохраните его заново в UTF-8. |
| Символы отображаются квадратами | Этих символов нет во встроенных шрифтах игры. |
| Файл целиком игнорируется | В этом файле синтаксическая ошибка JSON. `Player.log` записывает ошибку вместе с именем файла. |

Файл лога находится по пути `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log`. Найдите в нём строку «모드 내 언어 파일 발견» (найден языковой файл в моде), чтобы увидеть, какие файлы были прочитаны и сколько ключей было в каждом.

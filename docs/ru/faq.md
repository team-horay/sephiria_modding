# FAQ


## Как посмотреть логи?

Логи игры записываются в файл ниже. Он перезаписывается при каждом запуске игры, а лог предыдущего запуска сохраняется в `Player-prev.log`.

```
%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log
```

Строки, относящиеся к модам, начинаются с тега в квадратных скобках, поэтому ищите по этому тегу.

| Тег | Содержание |
|---|---|
| `[WorkshopModManager]` | Получение списка подписок, загрузки, сканирование локальной папки, сводка плана загрузки |
| `[WorkshopModRuntime]` | Активация DLL и результаты слияния локализации |
| `[WorkshopUploader]` | Загрузка в Мастерскую и отправка на проверку |
| `[ModGuardClient]` | Обмен данными с сервером проверки |
| `[WorkshopLobbyMods]` | Сравнение наборов модов в многопользовательских комнатах |
| `모드 내 언어 파일 발견` | Количество ключей, прочитанных из каждого файла локализации |


## Что такое «Локальный мод (папка AddOns)» в панели Мастерской Steam?

В панели вы можете увидеть пункт «Локальный мод (папка AddOns)». Это устаревшая система моддинга, поэтому не используйте её для новых модов.
Устаревшие моды нельзя синхронизировать с другими игроками, поэтому рекомендуем их удалить.


## Я хочу перенести папку WorkshopLocal из папки установки Sephiria в другое место.

Если вы хотите хранить моды на другом диске или в рабочей папке, путь можно передать аргументом запуска. В библиотеке Steam откройте Sephiria → Свойства → Общие → Параметры запуска и введите:

```
-workshop_local=D:\mods\my-first-mod
```

Несколько путей разделяйте точкой с запятой, а если путь содержит пробелы, заключите всё выражение в кавычки.

```
"-workshop_local=D:\My Mods\first;D:\My Mods\second"
```

Папки, переданные аргументом, обрабатываются точно так же, как подпапки `WorkshopLocal/`.


## Я потерял uploadticket.json.

`mod-guard-manifest.json` и `mod-guard.sig.json` начиная с версии 1.1.1 больше не используются, поэтому их потеря не страшна. Нужен только файл `uploadticket.json`.

Если вы потеряли `uploadticket.json` (например, после переустановки системы), игра считает папку новым модом, и при загрузке как есть будет создан новый элемент Мастерской вместо обновления существующего. Чтобы продолжать обновлять существующий элемент, восстановите его в следующем порядке:

1. Подпишитесь на собственный мод в Мастерской.
2. Скопируйте папку, загруженную Steam, целиком (`<библиотека Steam>/steamapps/workshop/content/2436940/<ID элемента Мастерской>/`) в `WorkshopLocal/`. Имя папки может быть любым.
3. В скопированной папке создайте `uploadticket.json` с содержимым ниже. В качестве числа используйте цифры после `id=` в URL страницы Мастерской.
```json
{
  "modId": "yourname.first-mod",
  "publishedFileId": 123456789
}
```
4. Запустите игру, выберите мод в панели и нажмите **Загрузить в Мастерскую**. **Существующий элемент будет обновлён**, а если это мод с кодом, он будет повторно отправлен на проверку под тем же ID элемента. (Внимание: если вы скопировали существующую папку мода, чтобы сделать другой мод, **обязательно удалите** `uploadticket.json`. Если его оставить, новый мод перезапишет элемент Мастерской исходного мода.)

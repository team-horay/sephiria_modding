# Моды костюмов

Давайте добавим костюм, используя только PNG- и JSON-файлы, без кода. Мод такого типа может добавить две вещи:

- **Новые костюмы**: создание совершенно нового костюма. Можно задать его внешний вид, характеристики, стартовые предметы и многое другое.
- **Облики для существующих костюмов**: добавление облика (скина) к существующему костюму, например к Розовому кролику.

Эта страница основана на примере [`examples/costume-sample`](../../examples/costume-sample). Скачайте его, чтобы разобраться в структуре мода.

## Структура мода

```
costume-sample/
├── metadata.json
├── thumbnail.png
├── Costumes/                  ← папка костюмов
│   └── WhiteCat/              ← одна папка = один костюм
│       ├── costume.json
│       ├── icon.png
│       ├── idle.png
│       ├── move.png
│       ├── idle_back.png
│       ├── move_back.png
│       ├── attack.png
│       └── ...                ← PNG остальных движений
└── Localization/              ← текст названия и описания костюма
    ├── ko-KR.json
    ├── en-US.json
    └── ...
```


## metadata.json

Когда будете собирать свой мод на основе примера, измените `modId` и `author` в `metadata.json`. (Подробности см. в разделе [`metadata.json`](metadata.md).)

```json
{
  "info": {
    "title": { "ko-KR": "하얀 고양이 코스튬", "en-US": "White Cat Costume" },
    "description": { "ko-KR": "하얀 고양이 코스튬을 추가합니다.", "en-US": "Adds the White Cat costume." }
  },
  "tags": ["Costume"],
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.costume-whitecat",
    "version": "1.0.0",
    "author": "Your Name",
    "multiplayer": { "installation": "everyone" },
    "modules": [
      { "type": "costume", "path": "Costumes" },
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```


## Спрайтовые анимации

- Если делать все анимации, костюму их потребуется довольно много.
- Если это ваш первый костюм, попробуйте сделать простой вариант только с `idle, move, airborne, fall`.

| Движение | Описание | Обязательно |
|---|---|---|
| `idle` | Покой | Обязательно |
| `move` | Движение | Обязательно |
| `airborne` | В воздухе | Необязательно |
| `fall` | Падение без сил | Необязательно |
| `attack` | Атака | Необязательно |
| `greatsword_lower` | Круговой замах | Необязательно |
| `greatsword_sweep` | Вращение | Необязательно |
| `hitfeedback` | Получение урона | Необязательно |

### Анимации со спины

- Чтобы костюм выглядел естественнее, можно нарисовать спрайты со спины. Это необязательно.
- Если вы решили добавить спрайты со спины, обязательно включите движения `idle_back, move_back`.
- Анимации со спины определяются следующим образом.

| Движение | Описание |
|---|---|
| `idle_back` | Покой (спина) |
| `move_back` | Движение (спина) |
| `attack_back` | Атака (спина) |
| `greatsword_upper` | Круговой замах (спина) |

## Подготовка графики

- Для каждого движения сделайте PNG-спрайтлист, в котором кадры этого движения расположены по горизонтали.
- Высота изображения равна высоте кадра, а ширина равна ширине кадра × количество кадров. Не оставляйте промежутков между кадрами.
- Рекомендуем делать все отдельные изображения одного размера.
- В примере с Белым котом, где каждый спрайт имеет размер 20×16, размеры изображений следующие.

| Файл | Размер | Кадры |
|---|---|---|
| `idle.png` | 120×16 | 6 |
| `move.png` | 160×16 | 8 |
| `attack.png` | 60×16 | 3 |
| `fall.png` | 20×16 | 1 |

### Описание нового костюма

Опишите свой костюм в файле `costume.json`.

Пример `Costumes/WhiteCat/costume.json`:

```json
{
  "schemaVersion": 1,
  "id": "whitecat",
  "name": "Costume_WhiteCat_Name",
  "flavorText": "Costume_WhiteCat_FlavorText",
  "icon": "icon.png",

  "frameSize": [20, 16],
  "pivot": [10, 2],
  "pixelsPerUnit": 16,

  "animations": {
    "idle":             { "file": "idle.png", "fps": 12 },
    "idle_back":        { "file": "idle_back.png", "fps": 12 },
    "move":             { "file": "move.png", "fps": 4, "footstepFrames": [3, 7] },
    "move_back":        { "file": "move_back.png", "fps": 4, "footstepFrames": [3, 7] },
    "attack":           { "file": "attack.png", "fps": 20, "loop": false },
    "attack_back":      { "file": "attack_back.png", "fps": 20, "loop": false },
    "greatsword_lower": { "file": "greatsword_lower.png", "fps": 20, "loop": false },
    "greatsword_upper": { "file": "greatsword_upper.png", "fps": 20, "loop": false },
    "greatsword_sweep": { "file": "greatsword_sweep.png", "fps": 30, "loop": false },
    "airborne":         { "file": "airborne.png", "fps": 12 },
    "fall":             { "file": "fall.png", "fps": 1 },
    "hitfeedback":      { "file": "hitfeedback.png", "fps": 20, "loop": false }
  },

  "stats": ["DEFENSE/-10", "EVASION/1200"],
  "startingItems": [],
  "onlyDefaultWeapon": false
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `schemaVersion` | Да | Идентификатор формата. Укажите целое число `1`. |
| `id` | Да | Используйте строчные латинские буквы, цифры, подчёркивания и дефисы, от 1 до 31 символа. Во избежание совпадений в игре он регистрируется как `<modId>:<id>`. |
| `name` | Да | **Ключ локализации** для названия костюма. См. раздел [Подготовка файлов локализации](#подготовка-файлов-локализации) ниже. |
| `flavorText` | Нет | **Ключ локализации** для описания костюма. См. раздел [Подготовка файлов локализации](#подготовка-файлов-локализации) ниже. |
| `icon` | Да | Путь к PNG-иконке превью костюма. |
| `face` | Нет | Путь к PNG-изображению лица для HUD многопользовательской игры. |
| `pixelsPerUnit` | Нет | Измените, чтобы использовать более детализированную графику. Чем выше значение, тем детальнее отрисовывается графика. PPU по умолчанию: 16. |
| `frameSize` | Нет | `[ширина, высота]` каждого спрайта. По умолчанию: `[16, 16]`. |
| `pivot` | Нет | Опорная точка каждого спрайта. Левый нижний угол: `[0, 0]`. По умолчанию: `[width/2, 0]`. |
| `animations` | Да | Графика для каждого движения. См. [animations](#animations). |
| `stats` | Нет | Список задаваемых характеристик. См. [Список характеристик](stats.md). |
| `startingItems` | Нет | Массив ID стартовых предметов. См. [Список предметов](item-table.md). |
| `body` | Нет | Задаёт хитбокс. См. [body](#body). |
| `skins` | Нет | Дополнительные облики того же костюма. См. [skins](#skins). |

### animations

```json
  "animations": {
    "idle":      { "file": "idle.png", "fps": 12 },
    "move":      { "file": "move.png", "fps": 4, "footstepFrames": [3, 7] },
    "attack":    { "file": "attack.png", "fps": 20, "loop": false },
    "fall":      { "file": "fall.png", "fps": 1 },
    "hitfeedback": { "file": "hitfeedback.png", "fps": 20, "loop": false, "frameSize": [24, 16], "pivot": [12, 2] }
  }
```

- Опишите подготовленные выше анимации четырьмя свойствами: `{ "file", "fps", "loop", "footstepFrames" }`.
- Для каждого движения можно также отдельно задать `frameSize` и `pivot`.
- Если какое-то одно движение нарисовано в другом размере, как в последней строке, задайте `frameSize` и `pivot` для этого движения.

#### Свойства

| Поле | Обязательно | Описание |
|---|---|---|
| `file` | Да | Имя воспроизводимого файла. |
| `fps` | Нет | Скорость воспроизведения анимации. (По умолчанию: 12) |
| `loop` | Нет | Зацикливать ли анимацию. (По умолчанию: true; для анимаций атаки false) |
| `footstepFrames` | Нет | Номера кадров, начиная с нуля. При показе этих кадров воспроизводится звук шагов. |


### body

```json
"body": { "hitboxRadius": 4, "hitboxOffset": [0, 4], "movementRadius": 0.25, "bodyScale": 1 }
```

- Определяет области столкновений персонажа при движении и получении ударов.
- Встроенные костюмы используют эти значения по умолчанию.
- Если нет особой причины, рекомендуем не указывать этот раздел.

#### Свойства

| Поле | Обязательно | Описание |
|---|---|---|
| `hitboxRadius` | Нет | Радиус окружности хитбокса в пикселях, от 0,5 до 64. По умолчанию `4`. |
| `hitboxOffset` | Нет | Центр окружности хитбокса, `[x, y]`, в пикселях относительно опорной точки; положительный x направлен вправо, положительный y вверх, ±64. По умолчанию `[0, 4]`. |
| `movementRadius` | Нет | Радиус окружности столкновений при движении, которая сталкивается со стенами и препятствиями, в юнитах (16 пикселей = 1), от 0,05 до 2. По умолчанию `0.25`. |
| `bodyScale` | Нет | Масштаб положения плеча, в котором удерживается оружие, от 0,1 до 4. По умолчанию `1`. Увеличьте, если оружие утопает в теле крупного костюма. |



### skins

```json
"skins": [
  { "id": "winter", "name": "Skin_WhiteCat_Winter_Name", "folder": "skins/Winter", "icon": "icon.png",
    "animations": { "idle": "idle.png", "move": "move.png" } }
]
```

- Добавляет дополнительные облики тому же костюму.
- Анимации описываются в том же формате, что и выше.
- Если `frameSize` или `pivot` не указаны, используются значения самого костюма.




## Подготовка файлов локализации

`Localization/ko-KR.json`:

```json
{
  "Costume_WhiteCat_Name": "하얀 고양이",
  "Costume_WhiteCat_FlavorText": "줄무늬가 인상적입니다."
}
```

`Localization/en-US.json`:

```json
{
  "Costume_WhiteCat_Name": "White Cat",
  "Costume_WhiteCat_FlavorText": "The stripes are rather impressive."
}
```

- В `name` и `flavorText` указывайте вместо текста **ключ локализации**, а сам текст помещайте в папку `Localization/` того же мода, по одному файлу на язык.
- Для ключей используйте латинские буквы, цифры, подчёркивания и дефисы, без пробелов. Включение названия мода в ключ помогает избежать совпадений с другими модами.
- Если ключа **нет ни в одном языковом файле**, костюм не загрузится. Нужно указать хотя бы один язык.
- Рекомендуем также добавить английский (`en-US`), чтобы вашим костюмом могло пользоваться больше людей.
- Не забудьте также объявить модуль `localization` в `modules` файла `metadata.json`.



## Проверьте результат

1. Поместите папку мода в `WorkshopLocal/` и запустите игру.
2. Начните игру, откройте выбор костюма в деревне (**Сменить костюм**) и убедитесь, что ваш новый костюм добавлен.
3. Если вы изменили содержимое костюма, игру нужно перезапустить.



## Дополнительно: добавление только скина к существующему костюму

Облик для существующего костюма можно создать, сделав `skin.json` вместо `costume.json`.

```
Costumes/
└── PinkRabbit_Pajama/
    ├── skin.json
    ├── icon.png
    ├── idle.png
    └── move.png
```

```json
{
  "schemaVersion": 1,
  "costume": "PinkRabbit",
  "id": "pajama",
  "name": "Skin_PinkRabbit_Pajama_Name",
  "icon": "icon.png",
  "animations": { "idle": "idle.png", "move": "move.png" }
}
```

- `costume` является id целевого костюма. Используйте id встроенного костюма (например, `PinkRabbit`) или, для костюма из другого мода, его id во время выполнения, включая имя мода. (Для примера с Белым котом: `yourname.costume-whitecat:whitecat`.)
- `stats`, `startingItems`, `body`, `skins` и `flavorText` берутся из существующего костюма как есть, поэтому задать их нельзя.
- Переопределение облика по умолчанию у встроенного костюма не поддерживается.

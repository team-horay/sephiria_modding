# 发布到创意工坊

本页介绍如何把模组上传到 Steam 创意工坊、审核系统的工作方式，以及多人游戏中模组如何在玩家之间同步。


## 上传之前

- 上传模组到创意工坊需要预览图（PNG 或 JPG，小于 1 MB）。通过 `info.preview` 设置，或在模组文件夹中放一个 `thumbnail.png`。详情请参阅 [metadata.json 参考](metadata.md#preview)。
- `info.title` 最多 128 个字符，`info.description` 最多 7999 个字符。如果你写了多种语言，创意工坊页面上使用的是 `en-US` 版本。
- 在 `tags` 中填写创意工坊分类。可用的分类请参阅 [metadata.json 参考](metadata.md)。
- 文件夹中的每个文件都会被审核，所以请确保模组文件夹中不包含游戏 DLL 的副本、`.pdb` 文件或构建的中间产物。

## 发布步骤

1. 启动 Sephiria。
2. 在标题画面打开 **Steam 创意工坊** 面板，找到你制作的模组。
3. 选择你的模组，然后点击**上传到创意工坊**。
4. 不含代码的模组，上传到创意工坊后即完成发布。
5. 包含代码（DLL）的模组在上传到创意工坊完成后，会连同创意工坊物品 ID 一起自动提交到**审核系统**。
6. 前往上传后的创意工坊页面，进行订阅等最终测试，然后把可见性改为“公开”。

如果已经上传到创意工坊，只是审核提交失败了（例如因为网络错误），请对同一个模组再次点击**上传到创意工坊**。如果内容没有变化，模组不会再次上传到创意工坊，只会重新发送提交。提交必须使用创建该创意工坊物品的 Steam 账号进行。

## 代码审核

- 审核系统会反编译 DLL，并检查网络通信、文件访问、混淆和恶意行为。审核结合了自动分析和人工检查，我们也明白没有任何审核系统能够发现所有风险。即便如此，我们仍希望通过这一审核流程来减少恶意模组的传播。感谢你的配合。
- 所有包含代码（DLL）的模组**也必须提交到模组审核系统**。为此，请务必使用游戏内的**上传到创意工坊**按钮进行上传。
- 已上传到创意工坊但未提交到审核系统的模组，原则上玩家无法运行。
- 下载模组的玩家会通过模组的创意工坊物品 ID 和已安装的 DLL 查询其审核状态。
  - **已提交 / 已批准**：模组会运行。即使审核尚未完成也会运行。
  - **未提交 / 已驳回**：模组不会运行，并在模组面板中显示原因。
- 如果在审核中发现问题，模组即使已经发布也可能被驳回。对于被驳回的模组，可以通过面板中的**查看驳回原因**查看原因。被驳回的 DLL 不能原样再次发布；请修复问题后重新上传。
- 即使没有 `dll` 模块，只要有 `libraries`，或者包含改了扩展名的 DLL 或 EXE，模组同样需要审核。
- 需要代码审核的模组，文件夹压缩后必须在 20 MB 以内。

### 审核失败原因

|消息|原因|
|---|---|
|审核系统中没有提交记录。|模组已上传到创意工坊，但没有提交到审核系统。请通过**上传到创意工坊**按钮重新提交。|
|审核系统已驳回该模组的批准。|运营团队因某种原因驳回了该模组。请查看驳回原因。|
|无法从审核服务器获取信息。|订阅者的网络连接可能已断开，或者审核服务器可能出现了问题。|
|这是旧审核系统的模组。|审核服务器已升级，模组原有的验证数据已被重置。请重新提交。|
|在模组中检测到未经授权的DLL。|如果模组运行期间模组内的 DLL 文件组成发生变化，该模组的加载会受到限制。也就是说，以下做法可能违反审核系统：模组在运行时从外部下载 DLL 并加载程序集；模组在运行时自行生成并运行 DLL；模组将以自有压缩方式打包在内部的 DLL 解压后使用。|

## 可见性与公开

- 首次上传时，可见性设为 `Unlisted`（隐藏）。
- 公开之前，请先自行订阅，确认安装后的副本能正常运行，再改为“公开”。
- 页面描述、截图、其他语言的描述等都可以在 Steam 创意工坊的物品页面中编辑。

## 更新模组

更新模组的方式与发布相同。

- 更改了 DLL 的更新会在上传后自动重新提交，并再次经过审核。如果没有更改任何 DLL，审核状态保持不变。
- 不要更改 `modId`。否则会被当作另一个模组，可能导致依赖关系等出问题。
- **每次更新都务必提升 `metadata.json` 中的 `version`。** 加入多人游戏大厅时会比较模组版本，如果内容变了而版本没变，模组内容不同的玩家可能进入同一局游戏并遇到问题。

## 上传票据

上传后，模组文件夹中会添加 `uploadticket.json`。它包含你的创意工坊物品 ID 和审核提交信息，所以**请不要删除**。如果你用 git 管理模组文件夹，最稳妥的做法是把这个文件也一并提交。更换电脑或重装系统时，需要这个文件才能继续更新同一个创意工坊物品。没有它，游戏会把该文件夹视为从未发布过的新模组。

1.1.1 之前的审核系统所使用的 `mod-guard-manifest.json` 和 `mod-guard.sig.json` 已不再使用。即使它们仍然存在，也不会被上传到创意工坊，可以删除。

丢失该文件后的恢复方法请参阅[常见问题](faq.md)。


## 多人游戏规则

### 多人游戏大厅设置

主机创建多人游戏大厅时，**主机已启用的模组列表**会注册到大厅中。

- `installation` 为 `host_only` 的模组：参与者无需安装，只会显示在列表中。
- `multiplayer.installation` 为 `everyone`（或未声明）的模组：参与者也必须安装。
- 服装模组和数据模组：参与者也必须安装。

### 加入

如果玩家当前的模组配置与大厅不同，需要经过以下步骤：下载 → 启用 → 重启游戏并再次尝试加入。

### 安装在 WorkshopLocal 中的测试模组

加载了 `WorkshopLocal/` 中本地模组的游戏无法进行多人游戏。要测试多人游戏，请把模组上传到创意工坊，清空本地文件夹，然后使用订阅的副本。即使物品处于 `Unlisted` 状态，也可以通过链接订阅。

# ม็อดแปลภาษา

[ม็อดแรกของคุณ](getting-started.md) ได้อธิบายพื้นฐานของการทำม็อดไปแล้ว หน้านี้จึงครอบคลุมกฎทั่วไปสำหรับม็อดแปลภาษา
[`examples/translation-sample`](../../examples/translation-sample) มีตัวอย่างสมบูรณ์ที่คุณคัดลอกไปวางใน `WorkshopLocal/` เพื่อลองใช้ได้ทันที



## หลักการทำงาน

- เกมมีตาราง **คีย์ → สตริง** หนึ่งตารางต่อหนึ่งภาษา เมื่อม็อดถูกโหลด ค่าในม็อดจะเขียนทับตารางต้นฉบับ
- ไฟล์ของคุณใส่เฉพาะคีย์ที่ต้องการเปลี่ยนก็เพียงพอ
- ชื่อไฟล์คือภาษา `ko-KR.json` จะเขียนทับตารางภาษาเกาหลี และ `en-US.json` จะเขียนทับตารางภาษาอังกฤษ
- หากม็อดแปลภาษาหลายตัวตั้งค่าคีย์เดียวกัน ม็อดที่โหลดทีหลังจะชนะ
- ม็อดที่เปลี่ยนเฉพาะข้อความจะไม่มีผลต่อผู้เข้าร่วมคนอื่น จึงแนะนำให้ตั้งค่า `multiplayer.installation` ใน `metadata.json` เป็น `local_only`
- ทั้งคีย์และค่าเป็นสตริง ไม่อนุญาตให้ใช้ออบเจ็กต์ซ้อนและอาร์เรย์
- บันทึกไฟล์เป็น **UTF-8**

```
my-translation-mod/
├── metadata.json              ← เพิ่ม { "type": "localization", "path": "Localization" } ใน modules
├── thumbnail.png
└── Localization/
    └── ko-KR.json
```



## สิ่งที่ห้ามแปล

ข้อความในเกมมีนิพจน์ที่ถูกตีความขณะรันไทม์
ห้ามแปลข้อความด้านล่างนี้ ให้คงเป็นภาษาอังกฤษไว้ตามเดิมทุกประการ (คำนึงถึงตัวพิมพ์เล็ก-ใหญ่)

| ประเภท    | ตัวอย่าง                                                                     | คำอธิบาย                                 |
| ----- | --------------------------------------------------------------------------- | ------------------------------------------- |
| คีย์เวิร์ด   | `{VALUE}`, `{EFFECT0}`, `{LV}`, `{COUNT}`, `{ITEMNAME}`, `{COUNTER}/{GOAL}` | ถูกแทนที่ด้วยตัวเลขหรือชื่อขณะรันไทม์ ห้ามเปลี่ยนแม้แต่ตัวอักษรเดียวภายในวงเล็บปีกกา   |
| แท็กของเกม | `<tag=FinalDamage>`, `<tag=WeaponAction_Fury>`, `<tag=TEXT:Qliphoth>`       | ถูกแทนที่ด้วยทูลทิปคีย์เวิร์ดและไอคอน ชื่อภายในแท็กถูกกำหนดตายตัว รวมถึงตัวพิมพ์เล็ก-ใหญ่ |
| แท็กจัดรูปแบบ | `<color=red>…</color>`, `<sprite="Keyword" name=Dice>`, `<indent=10>`       | การจัดรูปแบบข้อความ แท็กเปิดและแท็กปิดต้องเป็นคู่กัน        |
| การขึ้นบรรทัดใหม่   | `\n`                                                                        | การขึ้นบรรทัดใหม่ภายในสตริง JSON                        |




## การเพิ่มภาษาใหม่

- คุณสามารถเพิ่มภาษาที่เกมไม่รองรับได้ด้วย หากชื่อไฟล์เป็นรหัสภาษาใหม่ เกมจะลงทะเบียนเป็นภาษาใหม่และแสดงในรายการตั้งค่าภาษา
- ไฟล์ภาษาต้นฉบับอยู่ที่ `<โฟลเดอร์ติดตั้งเกม>/Sephiria_Data/StreamingAssets/Localization/` หนึ่งไฟล์ต่อหนึ่งภาษา ใช้เป็นข้อมูลอ้างอิงเมื่อแปล
- ภาษาที่เกมรองรับอยู่แล้วคือ `ko-KR`, `en-US`, `ja-JP`, `zh-CN`, `zh-TW`, `de-DE`, `fr-FR`, `es-ES`, `it-IT`, `pl-PL`, `pt-BR`, `ru-RU`, `sv-SE`, `th-TH` และ `tr-TR`
- **แปลทุกคีย์** คีย์ที่ขาดหายไปจากไฟล์ม็อดของคุณจะไม่แสดงเป็นช่องว่าง แต่จะกลับไปใช้**ภาษาอังกฤษ** (หรือภาษาเกาหลีหากภาษาอังกฤษก็ขาดหายไปด้วย) วิธีเริ่มต้นที่ง่ายที่สุดคือคัดลอก `en-US.json` ต้นฉบับมา
- **กรอกคีย์การตั้งค่าที่ขึ้นต้นด้วย `#`** `#LanguageName` คือชื่อที่แสดงในรายการตั้งค่าภาษา และ `#FontName` คือฟอนต์ที่จะใช้ ปรับคีย์เครื่องหมายวรรคตอน เช่น `#Colon`, `#Bullet` และ `#ParenthesisOpen` ให้เหมาะกับธรรมเนียมของภาษานั้น
- สำหรับ `#FontName` คุณสามารถเลือกจากฟอนต์ที่มีอยู่ในเกมได้ เกมมีฟอนต์สำหรับระบบตัวอักษรต่อไปนี้

| ระบบตัวอักษร | `#FontName` |
|---|---|
| ละติน ซีริลลิก ฮันกึล | `GalCyrillic` |
| ญี่ปุ่น | `JF-Dot-MPlus10` |
| จีนตัวย่อ | `Fusion_Pixel_10_Simple` |
| จีนตัวเต็ม | `BoutiqueBitmap9x9` |
| ไทย | `NotoSansThai` |



## การแก้ไขปัญหา

| อาการ | สิ่งที่ต้องตรวจสอบ |
|---|---|
| เปิดใช้งานม็อดแล้วแต่ข้อความไม่เปลี่ยน | ชื่อคีย์ตรงกับต้นฉบับทุกตัวอักษรหรือไม่ ชื่อไฟล์ตรงกับภาษาปัจจุบันของเกมหรือไม่ (`ko-KR.json` มีผลเฉพาะในภาษาเกาหลี) |
| บางคีย์ไม่เปลี่ยน | มีม็อดแปลภาษาอื่นเขียนทับคีย์เดียวกันทีหลังหรือไม่ ลองเปลี่ยนลำดับในแผง |
| `{VALUE}` แสดงเป็นข้อความตามตัวอักษร | สะกดคีย์เวิร์ดต่างจากต้นฉบับ ให้คัดลอกจากข้อความต้นฉบับโดยตรง |
| `<tag=…>` แสดงเป็นข้อความตามตัวอักษร | การสะกดหรือตัวพิมพ์เล็ก-ใหญ่ของชื่อแท็กต่างออกไป |
| ข้อความภาษาเกาหลี (หรือภาษาอื่นที่ไม่ใช่อังกฤษ) แสดงเป็นตัวอักษรเพี้ยน | ไฟล์ไม่ใช่ UTF-8 บันทึกใหม่เป็น UTF-8 |
| ตัวอักษรแสดงเป็นกล่องสี่เหลี่ยม | ตัวอักษรเหล่านั้นไม่มีในฟอนต์ที่มีอยู่ในเกม |
| ทั้งไฟล์ถูกเพิกเฉย | ไฟล์นั้นมีข้อผิดพลาดไวยากรณ์ JSON `Player.log` จะบันทึกข้อผิดพลาดพร้อมชื่อไฟล์ไว้ |

ไฟล์ล็อกอยู่ที่ `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log` ค้นหาคำว่า "모드 내 언어 파일 발견" (พบไฟล์ภาษาในม็อด) เพื่อดูว่าไฟล์ใดถูกอ่านและแต่ละไฟล์มีกี่คีย์

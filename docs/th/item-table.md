# รายการไอเทม

ID ไอเทมสำหรับ `startingItems` ของชุดแต่งกาย

- ไม่รวมไอเทมที่ซ่อน ปิดใช้งาน และยังไม่ระบุชนิด
- **โปรดระวังไอเทมที่มีข้อมูลในคอลัมน์ปลดล็อก**
  - ไอเทมเหล่านี้ปลดล็อกผ่านจารึกแห่งโชคชะตา หรือได้รับเฉพาะผ่านเส้นทางเฉพาะ เช่น ร้านค้าในมิติกระเป๋า หรือพ่อค้าหมวกน่าสงสัย
  - ไอเทมที่ให้เป็นไอเทมเริ่มต้นจะได้รับไม่ว่าจะปลดล็อกแล้วหรือไม่ ดังนั้นให้เพิ่มเฉพาะเมื่อจำเป็นจริง ๆ เท่านั้น

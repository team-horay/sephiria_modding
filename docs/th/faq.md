# คำถามที่พบบ่อย


## จะดูล็อกได้อย่างไร?

ล็อกของเกมจะถูกเขียนลงไฟล์ด้านล่าง ไฟล์นี้จะถูกเขียนใหม่ทุกครั้งที่เปิดเกม และล็อกของการรันครั้งก่อนจะถูกเก็บไว้ใน `Player-prev.log`

```
%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log
```

บรรทัดที่เกี่ยวกับม็อดจะขึ้นต้นด้วยแท็กในวงเล็บเหลี่ยม ให้ค้นหาแท็กนั้น

| แท็ก | เนื้อหา |
|---|---|
| `[WorkshopModManager]` | การดึงรายการสมัครรับ การดาวน์โหลด การสแกนโฟลเดอร์ในเครื่อง สรุปแผนการโหลด |
| `[WorkshopModRuntime]` | ผลการเปิดใช้งาน DLL และการรวมไฟล์แปลภาษา |
| `[WorkshopUploader]` | การส่งตรวจสอบและการอัปโหลดขึ้น Workshop |
| `[ModGuardClient]` | การสื่อสารกับเซิร์ฟเวอร์ตรวจสอบ |
| `[WorkshopLobbyMods]` | การเปรียบเทียบชุดม็อดในห้องผู้เล่นหลายคน |
| `모드 내 언어 파일 발견` (ภาษาเกาหลี แปลว่า "พบไฟล์ภาษาในม็อด") | จำนวนคีย์ที่อ่านได้จากไฟล์แปลภาษาแต่ละไฟล์ |


## "ม็อดในเครื่อง (โฟลเดอร์ AddOns)" ในแผง Steam Workshop คืออะไร?

คุณอาจเห็นรายการ "ม็อดในเครื่อง (โฟลเดอร์ AddOns)" ในแผง นี่คือฟีเจอร์ทำม็อดแบบเก่า ดังนั้นอย่าใช้กับม็อดใหม่
ม็อดแบบเก่าไม่สามารถซิงก์กับผู้เล่นคนอื่นได้ จึงแนะนำให้ลบออก


## อยากย้ายโฟลเดอร์ WorkshopLocal ไปไว้ที่อื่นนอกเหนือจากโฟลเดอร์ติดตั้ง Sephiria

หากต้องการเก็บม็อดไว้ในไดรฟ์อื่นหรือโฟลเดอร์ทำงาน คุณสามารถส่งเส้นทางเป็นอาร์กิวเมนต์เปิดเกมได้ ในคลัง Steam ของคุณ ไปที่ Sephiria → คุณสมบัติ → ทั่วไป → ตัวเลือกการเปิดใช้ แล้วป้อน:

```
-workshop_local=D:\mods\my-first-mod
```

คั่นหลายเส้นทางด้วยเครื่องหมายอัฒภาค และครอบทั้งหมดด้วยเครื่องหมายคำพูดหากเส้นทางมีช่องว่าง

```
"-workshop_local=D:\My Mods\first;D:\My Mods\second"
```

โฟลเดอร์ที่ส่งเป็นอาร์กิวเมนต์จะถูกปฏิบัติเหมือนโฟลเดอร์ย่อยของ `WorkshopLocal/` ทุกประการ


## ฉันทำ uploadticket.json, mod-guard-manifest.json และ mod-guard.sig.json หาย

หากหายเฉพาะไฟล์ใบรับรอง (`mod-guard-manifest.json`, `mod-guard.sig.json`) และ `uploadticket.json` ยังอยู่ ให้เลือกม็อดในแผงแล้วกดปุ่ม **รับหลักฐานการอนุมัติ** เพื่อดาวน์โหลดไฟล์เหล่านั้นจากเซิร์ฟเวอร์ตรวจสอบอีกครั้ง แต่หากคุณทำ `uploadticket.json` หายด้วย (เช่น หลังฟอร์แมตเครื่อง) เกมจะถือว่าโฟลเดอร์เป็นม็อดใหม่ ดังนั้นการอัปโหลดทั้งอย่างนั้นจะสร้างไอเทม Workshop ใหม่แทนที่จะอัปเดตไอเทมเดิม หากต้องการอัปเดตไอเทมเดิมต่อไป ให้กู้คืนตามลำดับนี้:

1. สมัครรับม็อดของคุณเองบน Workshop
2. คัดลอกโฟลเดอร์ทั้งหมดที่ Steam ดาวน์โหลดมา (`<คลัง Steam>/steamapps/workshop/content/2436940/<ID ไอเทม Workshop>/`) ไปไว้ใน `WorkshopLocal/` ใช้ชื่อโฟลเดอร์อะไรก็ได้
3. ในโฟลเดอร์ที่คัดลอกมา สร้าง `uploadticket.json` ที่มีเนื้อหาด้านล่าง สำหรับตัวเลข ให้ใช้ตัวเลขหลัง `id=` ใน URL ของหน้า Workshop
```json
{
  "modId": "yourname.first-mod",
  "publishedFileId": 123456789
}
```
4. เมื่อเปิดเกม ม็อดจะแสดงเป็น "ยังไม่ส่งตรวจ" ในแผง ทำตามขั้นตอน ขอตรวจสอบ → อนุมัติ → รับหลักฐานการอนุมัติ → อัปโหลดขึ้น Workshop อีกครั้ง แล้ว**ไอเทมเดิมจะถูกอัปเดต** (หมายเหตุ: หากคุณคัดลอกโฟลเดอร์ม็อดที่มีอยู่เพื่อสร้างม็อดใหม่คนละตัว คุณ**ต้องลบ** `uploadticket.json` และไฟล์ใบรับรองออก หากปล่อยไว้ ม็อดใหม่จะเขียนทับไอเทม Workshop ของม็อดเดิม)

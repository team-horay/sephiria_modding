# ม็อดชุดแต่งกาย

มาเพิ่มชุดแต่งกายโดยใช้เพียงไฟล์ PNG และ JSON โดยไม่ต้องเขียนโค้ดกัน ม็อดประเภทนี้สามารถเพิ่มสองสิ่งต่อไปนี้ได้

- **ชุดแต่งกายใหม่**: สร้างชุดแต่งกายใหม่ทั้งชุด คุณสามารถกำหนดรูปลักษณ์ ค่าสถานะ ไอเทมเริ่มต้น และอื่น ๆ ได้
- **รูปลักษณ์สำหรับชุดแต่งกายที่มีอยู่**: เพิ่มรูปลักษณ์ (สกิน) ให้ชุดแต่งกายที่มีอยู่แล้ว เช่น กระต่ายชมพู

หน้านี้อ้างอิงจากตัวอย่าง [`examples/costume-sample`](../../examples/costume-sample) ดาวน์โหลดไปดูเพื่อทำความเข้าใจโครงสร้างของม็อด

## โครงสร้างม็อด

```
costume-sample/
├── metadata.json
├── thumbnail.png
├── Costumes/                  ← โฟลเดอร์ชุดแต่งกาย
│   └── WhiteCat/              ← หนึ่งโฟลเดอร์ = หนึ่งชุดแต่งกาย
│       ├── costume.json
│       ├── icon.png
│       ├── idle.png
│       ├── move.png
│       ├── idle_back.png
│       ├── move_back.png
│       ├── attack.png
│       └── ...                ← PNG ของท่าทางอื่น ๆ
└── Localization/              ← ข้อความชื่อและคำอธิบายชุดแต่งกาย
    ├── ko-KR.json
    ├── en-US.json
    └── ...
```


## metadata.json

เมื่อสร้างม็อดของคุณเองจากตัวอย่าง ให้เปลี่ยน `modId` และ `author` ใน `metadata.json` (ดูรายละเอียดที่ [`metadata.json`](metadata.md))

```json
{
  "info": {
    "title": { "ko-KR": "하얀 고양이 코스튬", "en-US": "White Cat Costume" },
    "description": { "ko-KR": "하얀 고양이 코스튬을 추가합니다.", "en-US": "Adds the White Cat costume." }
  },
  "tags": ["Costume"],
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.costume-whitecat",
    "version": "1.0.0",
    "author": "Your Name",
    "multiplayer": { "installation": "everyone" },
    "modules": [
      { "type": "costume", "path": "Costumes" },
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```


## แอนิเมชันสไปรต์

- ชุดแต่งกายหนึ่งชุดต้องใช้แอนิเมชันค่อนข้างมากหากใส่ครบทั้งหมด
- หากนี่คือชุดแต่งกายชุดแรกของคุณ ลองทำแบบง่าย ๆ ด้วย `idle, move, airborne, fall` เท่านั้นก่อน

| ท่าทาง | คำอธิบาย | จำเป็น |
|---|---|---|
| `idle` | ยืนนิ่ง | จำเป็น |
| `move` | เคลื่อนที่ | จำเป็น |
| `airborne` | ลอยอยู่กลางอากาศ | ไม่บังคับ |
| `fall` | ล้มลง | ไม่บังคับ |
| `attack` | โจมตี | ไม่บังคับ |
| `greatsword_lower` | เหวี่ยงหมุน | ไม่บังคับ |
| `greatsword_sweep` | หมุนตัว | ไม่บังคับ |
| `hitfeedback` | ถูกโจมตี | ไม่บังคับ |

### แอนิเมชันด้านหลัง

- เพื่อให้ชุดแต่งกายดูเป็นธรรมชาติยิ่งขึ้น คุณสามารถวาดสไปรต์ด้านหลังได้ ส่วนนี้ไม่บังคับ
- หากตัดสินใจเพิ่มสไปรต์ด้านหลัง คุณต้องใส่ท่าทาง `idle_back, move_back` ด้วย
- แอนิเมชันด้านหลังนิยามดังนี้

| ท่าทาง | คำอธิบาย |
|---|---|
| `idle_back` | ยืนนิ่ง (ด้านหลัง) |
| `move_back` | เคลื่อนที่ (ด้านหลัง) |
| `attack_back` | โจมตี (ด้านหลัง) |
| `greatsword_upper` | เหวี่ยงหมุน (ด้านหลัง) |

## การเตรียมภาพ

- สำหรับแต่ละท่าทาง ให้สร้างสไปรต์ชีต PNG ที่เรียงเฟรมของท่าทางนั้นในแนวนอน
- ความสูงของภาพเท่ากับความสูงของเฟรม และความกว้างคือ ความกว้างเฟรม × จำนวนเฟรม อย่าเว้นช่องว่างระหว่างเฟรม
- แนะนำให้ทำภาพแต่ละภาพให้มีขนาดเท่ากันทั้งหมด
- ในตัวอย่าง White Cat ซึ่งแต่ละสไปรต์มีขนาด 20×16 ขนาดภาพจะเป็นดังนี้

| ไฟล์ | ขนาด | จำนวนเฟรม |
|---|---|---|
| `idle.png` | 120×16 | 6 |
| `move.png` | 160×16 | 8 |
| `attack.png` | 60×16 | 3 |
| `fall.png` | 20×16 | 1 |

*ภาพตัวอย่าง*


### การเขียนข้อมูลของชุดแต่งกายใหม่

นิยามชุดแต่งกายของคุณเองโดยเขียนไฟล์ `costume.json`

ตัวอย่าง `Costumes/WhiteCat/costume.json`:

```json
{
  "schemaVersion": 1,
  "id": "whitecat",
  "name": "Costume_WhiteCat_Name",
  "flavorText": "Costume_WhiteCat_FlavorText",
  "icon": "icon.png",

  "frameSize": [20, 16],
  "pivot": [10, 2],
  "pixelsPerUnit": 16,

  "animations": {
    "idle":             { "file": "idle.png", "fps": 12 },
    "idle_back":        { "file": "idle_back.png", "fps": 12 },
    "move":             { "file": "move.png", "fps": 4, "footstepFrames": [3, 7] },
    "move_back":        { "file": "move_back.png", "fps": 4, "footstepFrames": [3, 7] },
    "attack":           { "file": "attack.png", "fps": 20, "loop": false },
    "attack_back":      { "file": "attack_back.png", "fps": 20, "loop": false },
    "greatsword_lower": { "file": "greatsword_lower.png", "fps": 20, "loop": false },
    "greatsword_upper": { "file": "greatsword_upper.png", "fps": 20, "loop": false },
    "greatsword_sweep": { "file": "greatsword_sweep.png", "fps": 30, "loop": false },
    "airborne":         { "file": "airborne.png", "fps": 12 },
    "fall":             { "file": "fall.png", "fps": 1 },
    "hitfeedback":      { "file": "hitfeedback.png", "fps": 20, "loop": false }
  },

  "stats": ["DEFENSE/-10", "EVASION/1200"],
  "startingItems": [],
  "onlyDefaultWeapon": false
}
```

| ฟิลด์ | จำเป็น | คำอธิบาย |
|---|---|---|
| `schemaVersion` | ใช่ | ตัวระบุรูปแบบ ใส่จำนวนเต็ม `1` |
| `id` | ใช่ | ใช้ตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข ขีดล่าง และขีดกลาง ความยาว 1–31 ตัวอักษร เพื่อหลีกเลี่ยงการซ้ำกัน จะถูกลงทะเบียนในเกมเป็น `<modId>:<id>` |
| `name` | ใช่ | **คีย์แปลภาษา**ของชื่อชุดแต่งกาย ดู [การเตรียมไฟล์แปลภาษา](#การเตรียมไฟล์แปลภาษา) ด้านล่าง |
| `flavorText` | ไม่ | **คีย์แปลภาษา**ของคำอธิบายชุดแต่งกาย ดู [การเตรียมไฟล์แปลภาษา](#การเตรียมไฟล์แปลภาษา) ด้านล่าง |
| `icon` | ใช่ | เส้นทางไปยัง PNG ไอคอนตัวอย่างของชุดแต่งกาย |
| `face` | ไม่ | เส้นทางไปยัง PNG ใบหน้าสำหรับ HUD ของโหมดผู้เล่นหลายคน |
| `pixelsPerUnit` | ไม่ | เปลี่ยนค่านี้เพื่อใช้ภาพที่ละเอียดขึ้น ค่าที่สูงขึ้นจะเรนเดอร์ภาพในรายละเอียดที่ละเอียดกว่า ค่า PPU เริ่มต้นคือ 16 |
| `frameSize` | ไม่ | `[ความกว้าง, ความสูง]` ของแต่ละสไปรต์ ค่าเริ่มต้น: `[16, 16]` |
| `pivot` | ไม่ | จุดหมุนของแต่ละสไปรต์ มุมล่างซ้ายคือ `[0, 0]` ค่าเริ่มต้น: `[width/2, 0]` |
| `animations` | ใช่ | ภาพของแต่ละท่าทาง ดู [animations](#animations) |
| `stats` | ไม่ | รายการค่าสถานะที่จะตั้ง ดู [รายการค่าสถานะ](stats.md) |
| `startingItems` | ไม่ | อาร์เรย์ของ ID ไอเทมเริ่มต้น ดู [รายการไอเทม](item-table.md) |
| `body` | ไม่ | กำหนดฮิตบ็อกซ์ ดู [body](#body) |
| `skins` | ไม่ | รูปลักษณ์เพิ่มเติมสำหรับชุดแต่งกายเดียวกัน ดู [skins](#skins) |

### animations

```json
  "animations": {
    "idle":      { "file": "idle.png", "fps": 12 },
    "move":      { "file": "move.png", "fps": 4, "footstepFrames": [3, 7] },
    "attack":    { "file": "attack.png", "fps": 20, "loop": false },
    "fall":      { "file": "fall.png", "fps": 1 },
    "hitfeedback": { "file": "hitfeedback.png", "fps": 20, "loop": false, "frameSize": [24, 16], "pivot": [12, 2] }
  }
```

- นิยามแอนิเมชันที่เตรียมไว้ข้างต้นด้วยคุณสมบัติสี่อย่าง: `{ "file", "fps", "loop", "footstepFrames" }`
- คุณสามารถตั้งค่า `frameSize` และ `pivot` แยกสำหรับแต่ละท่าทางได้ด้วย
- หากคุณวาดท่าทางใดท่าทางหนึ่งในขนาดที่ต่างออกไป ดังในบรรทัดสุดท้าย ให้ตั้งค่า `frameSize` และ `pivot` ไว้ที่ท่าทางนั้น

#### คุณสมบัติ

| ฟิลด์ | จำเป็น | คำอธิบาย |
|---|---|---|
| `file` | ใช่ | ชื่อไฟล์ที่จะเล่น |
| `fps` | ไม่ | ความเร็วในการเล่นแอนิเมชัน (ค่าเริ่มต้น: 12) |
| `loop` | ไม่ | แอนิเมชันเล่นวนซ้ำหรือไม่ (ค่าเริ่มต้น: true; false สำหรับแอนิเมชันโจมตี) |
| `footstepFrames` | ไม่ | หมายเลขเฟรมเริ่มนับจากศูนย์ เสียงฝีเท้าจะเล่นเมื่อแสดงเฟรมเหล่านั้น |


### body

```json
"body": { "hitboxRadius": 4, "hitboxOffset": [0, 4], "movementRadius": 0.25, "bodyScale": 1 }
```

- นิยามพื้นที่การชนสำหรับการเคลื่อนที่และการถูกโจมตีของตัวละคร
- ชุดแต่งกายที่มีในเกมใช้ค่าเหล่านี้เป็นค่าเริ่มต้น
- หากไม่มีเหตุผลเฉพาะ แนะนำให้ละส่วนนี้ไว้

#### คุณสมบัติ

| ฟิลด์ | จำเป็น | คำอธิบาย |
|---|---|---|
| `hitboxRadius` | ไม่ | รัศมีของวงกลมฮิตบ็อกซ์ หน่วยเป็นพิกเซล 0.5–64 ค่าเริ่มต้น `4` |
| `hitboxOffset` | ไม่ | จุดศูนย์กลางของวงกลมฮิตบ็อกซ์ `[x, y]` หน่วยเป็นพิกเซลเทียบกับจุดหมุน x บวกคือขวา และ y บวกคือขึ้น ±64 ค่าเริ่มต้น `[0, 4]` |
| `movementRadius` | ไม่ | รัศมีของวงกลมการชนสำหรับการเคลื่อนที่ที่ชนกับกำแพงและสิ่งกีดขวาง หน่วยเป็นยูนิต (16 พิกเซล = 1) 0.05–2 ค่าเริ่มต้น `0.25` |
| `bodyScale` | ไม่ | สเกลของตำแหน่งไหล่ที่ถืออาวุธ 0.1–4 ค่าเริ่มต้น `1` เพิ่มค่านี้เมื่ออาวุธจมเข้าไปในลำตัวของชุดแต่งกายขนาดใหญ่ |



### skins

```json
"skins": [
  { "id": "winter", "name": "Skin_WhiteCat_Winter_Name", "folder": "skins/Winter", "icon": "icon.png",
    "animations": { "idle": "idle.png", "move": "move.png" } }
]
```

- เพิ่มรูปลักษณ์เพิ่มเติมให้ชุดแต่งกายเดียวกัน
- แอนิเมชันใช้รูปแบบเดียวกับข้างต้น
- หากละ `frameSize` หรือ `pivot` ไว้ จะใช้ค่าของชุดแต่งกายนั้นเอง




## การเตรียมไฟล์แปลภาษา

`Localization/ko-KR.json`:

```json
{
  "Costume_WhiteCat_Name": "하얀 고양이",
  "Costume_WhiteCat_FlavorText": "줄무늬가 인상적입니다."
}
```

`Localization/en-US.json`:

```json
{
  "Costume_WhiteCat_Name": "White Cat",
  "Costume_WhiteCat_FlavorText": "The stripes are rather impressive."
}
```

- ใน `name` และ `flavorText` ให้เขียน**คีย์แปลภาษา**แทนข้อความ แล้วใส่ข้อความไว้ในโฟลเดอร์ `Localization/` ของม็อดเดียวกัน หนึ่งไฟล์ต่อหนึ่งภาษา
- ใช้ตัวอักษรภาษาอังกฤษ ตัวเลข ขีดล่าง และขีดกลางสำหรับคีย์ โดยไม่มีช่องว่าง การใส่ชื่อม็อดของคุณไว้ในคีย์ช่วยหลีกเลี่ยงการซ้ำกับม็อดอื่น
- หากคีย์**ไม่มีในไฟล์ภาษาใดเลย** ชุดแต่งกายจะไม่ถูกโหลด คุณต้องมีอย่างน้อยหนึ่งภาษา
- แนะนำให้ใส่ภาษาอังกฤษ (`en-US`) ด้วย เพื่อให้ผู้คนจำนวนมากขึ้นได้สนุกกับชุดแต่งกายของคุณ
- อย่าลืมประกาศโมดูล `localization` ใน `modules` ของ `metadata.json` ด้วย



## ตรวจสอบผล

1. วางโฟลเดอร์ม็อดของคุณใน `WorkshopLocal/` แล้วเปิดเกม
2. เริ่มเกม เปิดหน้าเลือกชุดแต่งกายในหมู่บ้าน (**เปลี่ยนชุด**) แล้วตรวจสอบว่าชุดแต่งกายใหม่ของคุณถูกเพิ่มเข้ามาแล้ว
3. หากเปลี่ยนเนื้อหาของชุดแต่งกาย คุณต้องรีสตาร์ตเกม



## เพิ่มเติม: การเพิ่มเฉพาะสกินให้ชุดแต่งกายที่มีอยู่

คุณสามารถสร้างรูปลักษณ์สำหรับชุดแต่งกายที่มีอยู่แล้วได้โดยสร้าง `skin.json` แทน `costume.json`

```
Costumes/
└── PinkRabbit_Pajama/
    ├── skin.json
    ├── icon.png
    ├── idle.png
    └── move.png
```

```json
{
  "schemaVersion": 1,
  "costume": "PinkRabbit",
  "id": "pajama",
  "name": "Skin_PinkRabbit_Pajama_Name",
  "icon": "icon.png",
  "animations": { "idle": "idle.png", "move": "move.png" }
}
```

- `costume` คือ id ของชุดแต่งกายเป้าหมาย ใช้ id ของชุดแต่งกายที่มีในเกม (เช่น `PinkRabbit`) หรือสำหรับชุดแต่งกายของม็อดอื่น ให้ใช้ id ขณะรันไทม์ที่รวมชื่อม็อดด้วย (สำหรับตัวอย่าง White Cat คือ `yourname.costume-whitecat:whitecat`)
- `stats`, `startingItems`, `body`, `skins` และ `flavorText` จะมาจากชุดแต่งกายที่มีอยู่ตามเดิม จึงไม่สามารถตั้งค่าได้
- ไม่รองรับการแทนที่รูปลักษณ์เริ่มต้นของชุดแต่งกายที่มีในเกม

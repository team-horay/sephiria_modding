# คู่มือการทำม็อด Sephiria

ขอบคุณที่เข้าร่วมชุมชนม็อดของ Sephiria

นี่คือที่เก็บอย่างเป็นทางการของคู่มือ ตัวอย่าง และเทมเพลตสำหรับการทำม็อดของ [Sephiria](https://store.steampowered.com/app/2436940) คุณสามารถแบ่งปันม็อดผ่าน [Steam Workshop](https://steamcommunity.com/app/2436940/workshop/) ได้



## กฎ

เพื่อให้เกมปลอดภัยสำหรับทุกคน โปรดปฏิบัติตามกฎด้านล่างนี้ การละเมิดอาจส่งผลให้ถูกจำกัดการเผยแพร่ม็อดหรือการเล่นเกม

1. **ห้ามพฤติกรรมที่เป็นอันตราย**: ห้ามมัลแวร์ แบ็กดอร์ คีย์ล็อกเกอร์ โปรแกรมขุดคริปโต และฟีเจอร์อื่นใดที่ทำให้อุปกรณ์ บัญชี หรือข้อมูลของผู้ใช้ตกอยู่ในความเสี่ยง
2. **ใช้เพื่อวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์เท่านั้น**: ม็อดทั้งหมดต้องสร้างและเผยแพร่เพื่อวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์
3. **ห้ามละเมิดสิทธิ์หรือเนื้อหาที่เป็นอันตราย**: ห้ามเนื้อหาที่ละเมิดลิขสิทธิ์ ความเป็นส่วนตัว หรือสิทธิ์ในภาพลักษณ์ของผู้อื่น รวมถึงเนื้อหาทางเพศ หรือเนื้อหาที่ส่งเสริมความเกลียดชัง การคุกคาม หรือความรุนแรงในโลกจริง
4. **ห้ามรบกวนการเล่น**: ห้ามจงใจทำให้เกมทำงานผิดพลาด หรือแทรกแซงการเล่นตามปกติของผู้เล่นคนอื่น
5. **ห้ามเก็บข้อมูล**: ห้ามเก็บข้อมูลของผู้ใช้หรือส่งข้อมูลออกไปยังปลายทางภายนอก
6. **ห้ามหลบเลี่ยงการตรวจสอบสิทธิ์การเข้าถึง**: ห้ามหลบเลี่ยงการตรวจสอบการซื้อ ความเป็นเจ้าของ หรือสิทธิ์การเข้าถึงของเกมหรือแพลตฟอร์มจัดจำหน่ายโดยมิชอบ
7. **การตรวจสอบม็อด**: ม็อดที่มีโค้ด (DLL) จะต้องผ่านการตรวจสอบ ซึ่งรวมถึงการวิเคราะห์และการดีคอมไพล์เพื่อตรวจหาการละเมิดกฎ และหากพบปัญหา ม็อดอาจถูกปฏิเสธได้แม้จะเผยแพร่ไปแล้ว ห้ามปลอมแปลงผลการตรวจสอบหรือเครื่องหมายอนุมัติ ไฟล์ต้องอยู่ในสภาพที่ตรวจสอบได้ ห้ามทำ obfuscation
8. **การใช้แอสเซตของเกม**: อนุญาตให้ดีคอมไพล์และวิเคราะห์โค้ด ภาพ เสียง และแอสเซตอื่น ๆ ของเกมได้เท่าที่จำเป็นต่อการทำม็อด แต่ห้ามนำแอสเซตของเกมที่แยกออกมาไปเผยแพร่ซ้ำ
9. **ห้ามแอบอ้างหรือดัดแปลง**: ห้ามแอบอ้างเป็นผู้อื่น หรือดัดแปลงและเผยแพร่ซ้ำซึ่งม็อดที่ผู้อื่นสร้างโดยไม่ได้รับความยินยอม



## ก่อนเริ่มต้น

- ม็อดที่มีโค้ด (DLL) จะถูก**ส่งเข้าระบบตรวจสอบ**โดยอัตโนมัติเมื่อคุณอัปโหลดขึ้น Workshop การตรวจสอบจะเน้นตรวจหาพฤติกรรมที่เป็นอันตรายในโค้ด และม็อดที่ยังไม่ได้ส่งหรือถูกปฏิเสธจะไม่ทำงานในเกมของผู้เล่นคนอื่น ส่วนม็อดที่ไม่มีโค้ด เช่น ม็อดแปลภาษาและชุดแต่งกาย สามารถอัปโหลดได้ทันทีโดยไม่ต้องตรวจสอบ โปรดทราบว่าม็อดที่ระบบตรวจสอบอ่านไม่ได้จะถูกปฏิเสธ (ไฟล์ที่ถูก obfuscate, DLL ที่คอมไพล์จาก C/C++ ฯลฯ)
- ในโหมดผู้เล่นหลายคน ผู้เข้าร่วมทุกคนในห้องต้องเปิดใช้งานชุดม็อดเดียวกัน (ยกเว้นม็อด UI ส่วนตัว เช่น ม็อดแปลภาษา)
- หลังจากเปิดใช้งานม็อดแล้ว คุณต้องรีสตาร์ตเกมเพื่อเปลี่ยนลำดับหรือปิดใช้งานม็อดอีกครั้ง
- ม็อดที่สมัครรับไว้จะถูกปิดใช้งานเป็นค่าเริ่มต้น คุณสามารถเปิดใช้งานได้เองจากรายการ

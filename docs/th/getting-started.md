# ม็อดแรกของคุณ

คู่มือนี้อธิบายโครงสร้างพื้นฐานของม็อด Sephiria และพาคุณสร้างม็อดแรกพร้อมตรวจสอบผลในเกมทีละขั้นตอน

## สิ่งที่ต้องมี

- โปรแกรมแก้ไขข้อความที่ใช้งานได้ดี (เช่น [Visual Studio Code](https://code.visualstudio.com/))

## ค้นหาโฟลเดอร์ติดตั้งเกม

เปิดโฟลเดอร์ติดตั้งของ Sephiria

- จากคลัง Steam ของคุณ
  - `คลัง Steam → คลิกขวาที่ Sephiria → จัดการ → เรียกดูไฟล์ในเครื่อง`
- Windows (เส้นทางติดตั้งเริ่มต้น)
  - `C:\Program Files (x86)\Steam\steamapps\common\Sephiria`
- macOS (เส้นทางติดตั้งเริ่มต้น)
  - `~/Library/Application Support/Steam/steamapps/common/Sephiria` (โฟลเดอร์ที่มี `Sephiria.app` อยู่)

## สร้างโฟลเดอร์ WorkshopLocal และโฟลเดอร์ม็อดของคุณเอง

1. สร้างโฟลเดอร์ `WorkshopLocal/` ในโฟลเดอร์ติดตั้งเกม
2. สร้างโฟลเดอร์สำหรับม็อดของคุณเองไว้ข้างใน
   - Sephiria จะถือว่าแต่ละโฟลเดอร์คือม็อดหนึ่งตัว
   - ม็อดที่สร้างไว้ที่นี่สามารถทดสอบในเกมและอัปโหลดขึ้น Steam Workshop ได้

ในคู่มือนี้ คุณจะสร้าง `my-first-mod` ซึ่งเป็นม็อดที่เปลี่ยนข้อความของปุ่ม "เริ่มเกม" บนหน้าจอไตเติลให้เป็น "Hello World!" โครงสร้างเมื่อเสร็จแล้วจะเป็นดังนี้

```
<โฟลเดอร์ติดตั้งเกม>/
├── Sephiria.exe
└── WorkshopLocal/
    ├── my-first-mod/          ← ม็อดหนึ่งตัว
    │   ├── metadata.json      ← ไฟล์หลักที่นิยามม็อด
    │   ├── thumbnail.png      ← ภาพตัวอย่างของม็อด (จำเป็นสำหรับการอัปโหลดขึ้น Workshop)
    │   └── Localization/      ← โฟลเดอร์ที่โมดูล localization อ่าน
    │       └── en-US.json     ← ข้อความที่จะแทนที่
    └── another-mod/           ← ม็อดอีกตัว
        └── ...
```

## ไฟล์ metadata.json

- สร้าง `metadata.json` ในโฟลเดอร์ม็อดของคุณ แล้ววางเนื้อหาด้านล่างลงไป
- `metadata.json`: ไฟล์สำคัญที่นิยามม็อดของคุณ
- `yourname`: แทนที่ด้วยชื่อเล่นของคุณเอง
- บันทึกไฟล์เป็น **UTF-8** ใน Notepad ให้เลือก UTF-8 เป็น encoding ในหน้าต่าง "บันทึกเป็น"
- ดูความหมายของแต่ละฟิลด์ได้ที่ [อ้างอิง metadata.json](metadata.md)

```json
{
  "info": {
    "title": "My First Mod",
    "description": "Hello World!"
  },
  "mod": {
    "schemaVersion": 1,
    "modId": "yourname.my-first-mod",
    "version": "0.0.1",
    "author": "Your Name",
    "multiplayer": { "installation": "local_only" },
    "modules": [
      { "type": "localization", "path": "Localization" }
    ]
  }
}
```

## สร้างไฟล์ภาษา

- สร้างโฟลเดอร์ `Localization/` ในโฟลเดอร์ม็อดของคุณ
- สร้างไฟล์ `en-US.json` ที่มีเนื้อหาด้านล่างไว้ใน `Localization/`
- คุณสามารถเปลี่ยนชื่อไฟล์เป็นรหัสภาษาของคุณเองเพื่อทดสอบได้เช่นกัน

```json
{
  "Title_GameStart": "Hello World!"
}
```

## ตรวจสอบผล

ตอนนี้คุณสามารถตรวจสอบได้แล้วว่าม็อดทำงานหรือไม่

1. เปิด Sephiria
2. ตั้งค่าภาษาของเกมเป็นภาษาอังกฤษ แล้วดูที่หน้าจอไตเติล: ปุ่ม "Start Game" จะแสดงเป็น "Hello World!" ม็อดใน `WorkshopLocal/` จะถูกเปิดใช้งานเป็นค่าเริ่มต้น จึงไม่ต้องเปิดเอง
3. กดปุ่ม **Steam Workshop** บนหน้าจอไตเติลเพื่อเปิดแผง Workshop "My First Mod" ควรปรากฏในส่วน "ม็อดของฉัน"

### ม็อดของฉันไม่ทำงาน!

- ตรวจสอบว่าไวยากรณ์ JSON ถูกต้อง
- `path` ใน `metadata.json` ต้องตรงกับชื่อโฟลเดอร์จริงทุกประการ รวมถึงตัวพิมพ์เล็ก-ใหญ่
- ตรวจสอบว่า `metadata.json` ถูกเข้ารหัสเป็น UTF-8
- ตรวจสอบว่าภาษาของเกมตรงกับภาษาในชื่อไฟล์

## ขั้นตอนถัดไป

1. เรียนรู้วิธีนิยามม็อดได้ที่ [อ้างอิง metadata.json](metadata.md)
2. [ม็อดแปลภาษา](localization-mods.md) และ [ม็อดชุดแต่งกาย](costume-mods.md) ทำได้ค่อนข้างง่าย จึงแนะนำให้เริ่มจากสองอย่างนี้
3. [ม็อด DLL](dll-mods.md) เหมาะสำหรับผู้ที่มีพื้นฐานการเขียนโค้ด
4. เผยแพร่ม็อดของคุณบน Workshop ด้วย [การเผยแพร่บน Workshop](publishing.md)

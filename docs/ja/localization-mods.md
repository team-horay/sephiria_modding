# ローカライズMOD

[はじめてのMOD](getting-started.md) でMOD制作の基本を扱ったので、このページではローカライズMODに共通するルールを説明します。
[`examples/translation-sample`](../../examples/translation-sample) には、`WorkshopLocal/` にそのままコピーして試せる完全なサンプルがあります。



## 仕組み

- ゲームは言語ごとに **キー → 文字列** のテーブルを1つ持っています。MODがロードされると、MOD内の値が元のテーブルを上書きします。
- ファイルには、変更したいキーだけを書けば十分です。
- ファイル名が言語を表します。`ko-KR.json` は韓国語のテーブルを、`en-US.json` は英語のテーブルを上書きします。
- 複数のローカライズMODが同じキーを設定している場合、後からロードされたMODが優先されます。
- テキストだけを変更するMODは他の参加者に影響しないため、`metadata.json` の `multiplayer.installation` を `local_only` にすることをおすすめします。
- キーと値はどちらも文字列です。ネストしたオブジェクトや配列は使えません。
- ファイルは **UTF-8** で保存してください。

```
my-translation-mod/
├── metadata.json              ← modules に { "type": "localization", "path": "Localization" } を追加
├── thumbnail.png
└── Localization/
    └── ko-KR.json
```



## 翻訳してはいけないもの

ゲームのテキストには、実行時に解釈される表現が含まれています。
以下のテキストは翻訳せず、英語のまま正確に(大文字・小文字を区別して)残してください。

| 種類    | 例                                                                     | 説明                                 |
| ----- | --------------------------------------------------------------------------- | ------------------------------------------- |
| キーワード   | `{VALUE}`, `{EFFECT0}`, `{LV}`, `{COUNT}`, `{ITEMNAME}`, `{COUNTER}/{GOAL}` | 実行時に数値や名前に置き換えられます。波かっこの中は1文字も変えないでください。   |
| ゲームタグ | `<tag=FinalDamage>`, `<tag=WeaponAction_Fury>`, `<tag=TEXT:Qliphoth>`       | キーワードのツールチップやアイコンに置き換えられます。タグ内の名前は大文字・小文字を含めて固定です。 |
| 書式タグ | `<color=red>…</color>`, `<sprite="Keyword" name=Dice>`, `<indent=10>`       | テキストの書式設定です。開始タグと終了タグは対で書く必要があります。        |
| 改行   | `\n`                                                                        | JSON文字列内の改行です。                        |




## 新しい言語を追加する

- ゲームが対応していない言語を追加することもできます。ファイル名が新しい言語コードであれば、ゲームはそれを新しい言語として登録し、言語設定のリストに表示します。
- 元の言語ファイルは `<ゲームのインストールフォルダ>/Sephiria_Data/StreamingAssets/Localization/` に言語ごとに1つずつあります。翻訳の際の参考にしてください。
- ゲームがすでに対応している言語は `ko-KR`, `en-US`, `ja-JP`, `zh-CN`, `zh-TW`, `de-DE`, `fr-FR`, `es-ES`, `it-IT`, `pl-PL`, `pt-BR`, `ru-RU`, `sv-SE`, `th-TH`, `tr-TR` です。
- **すべてのキーを翻訳してください。** MODのファイルにないキーは空白で表示されるのではなく、**英語**(英語もなければ韓国語)にフォールバックします。元の `en-US.json` をコピーして始めるのが一番簡単です。
- **`#` で始まる設定キーを埋めてください。** `#LanguageName` は言語設定のリストに表示される名前で、`#FontName` は使用するフォントです。`#Colon`、`#Bullet`、`#ParenthesisOpen` などの句読点キーは、その言語の慣習に合わせて調整してください。
- `#FontName` には、ゲームに内蔵されているフォントから選べます。ゲームには次の文字体系用のフォントが含まれています。

| 文字体系 | `#FontName` |
|---|---|
| ラテン文字、キリル文字、ハングル | `GalCyrillic` |
| 日本語 | `JF-Dot-MPlus10` |
| 簡体字中国語 | `Fusion_Pixel_10_Simple` |
| 繁体字中国語 | `BoutiqueBitmap9x9` |
| タイ語 | `NotoSansThai` |



## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| MODは有効なのにテキストが変わらない | キー名が元のものと1文字残らず一致しているか。ファイル名が現在のゲーム言語と一致しているか(`ko-KR.json` は韓国語でしか適用されません)。 |
| 一部のキーだけ変わらない | 別のローカライズMODが同じキーを後から上書きしていないか。パネルで順序を変えてみてください。 |
| テキストに `{VALUE}` がそのまま表示される | キーワードの綴りが元のものと異なります。元のテキストからそのままコピーしてください。 |
| テキストに `<tag=…>` がそのまま表示される | タグ名の綴りか大文字・小文字が異なります。 |
| 日本語(など英語以外)のテキストが文字化けする | ファイルがUTF-8ではありません。UTF-8で保存し直してください。 |
| 文字が四角で表示される | その文字がゲーム内蔵フォントに含まれていません。 |
| ファイル全体が無視される | そのファイルにJSONの文法エラーがあります。`Player.log` にファイル名とともにエラーが記録されます。 |

ログファイルは `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log` にあります。「모드 내 언어 파일 발견」(MOD内の言語ファイルを発見)で検索すると、どのファイルが読み込まれ、それぞれ何個のキーがあったかを確認できます。

# Sephiria MOD制作ガイド

SephiriaのMODコミュニティへようこそ。

ここは [Sephiria](https://store.steampowered.com/app/2436940) のMOD制作ガイド、サンプル、テンプレートを集めた公式リポジトリです。作成したMODは [Steamワークショップ](https://steamcommunity.com/app/2436940/workshop/) を通じて共有できます。



## ルール

すべてのプレイヤーが安心して遊べるように、以下のルールを守ってください。違反した場合、MODの公開やゲームのプレイが制限されることがあります。

1. **悪意ある行為の禁止**: マルウェア、バックドア、キーロガー、マイニングプログラムなど、利用者の端末・アカウント・データを侵害する機能は禁止です。
2. **非商用利用**: すべてのMODは非商用目的で制作・配布しなければなりません。
3. **権利侵害および有害コンテンツの禁止**: 他者の著作権・個人情報・肖像権を侵害するもの、性的コンテンツを含むもの、ヘイト・嫌がらせ・現実の暴力を助長するものは禁止です。
4. **プレイ妨害の禁止**: ゲームを故意に誤作動させたり、他のプレイヤーの正常なプレイを妨害したりしてはなりません。
5. **情報収集の禁止**: 利用者の情報を収集したり、外部へ送信したりしてはなりません。
6. **権限迂回の禁止**: ゲームまたは配布プラットフォームの購入・所有・アクセス権限の確認を不正に迂回してはなりません。
7. **MOD審査**: コード(DLL)を含むMODは、ルール違反の有無を確認するため、解析や逆コンパイルを含む審査を受けてから承認されます。承認まで時間がかかる場合があります。審査結果や承認表示を偽造してはなりません。ファイルは審査可能な状態で提供する必要があり、難読化は禁止です。
8. **ゲーム資産の利用**: ゲームのコード・アート・サウンドなどの逆コンパイル・解析は、MOD制作に必要な範囲で許可されます。ただし、抽出したゲーム資産そのものを再配布してはなりません。
9. **なりすましおよび改変の禁止**: 他者になりすましたり、他人が制作したMODを同意なく改変・再配布したりしてはなりません。



## はじめる前に

- コード(DLL)を含むMODは、ワークショップにアップロードする前に**審査**を受けます。審査では主にコードに悪意ある動作がないかを確認します。翻訳やコスチュームなど、コードを含まないMODは審査なしですぐにアップロードできます。なお、審査システムが読み取れないMOD(難読化されたファイル、C/C++でコンパイルしたDLLなど)は却下されます。
- マルチプレイでは、ルームの参加者全員が同じMOD構成を有効にしている必要があります。(翻訳などの個人用UI MODは除きます。)
- MODを有効にした後、順序を変更したり再び無効にしたりするには、ゲームの再起動が必要です。
- 購読したMODは初期状態では無効になっています。リストから自分で有効にしてください。
